# Ключи сидов, которых наш код НЕ читает намеренно, — по строке на случай, каждая с причиной.
#
# Формат: <ключ>|<причина>
# Набор сидов `.vibe` общий с VibeIDE (submodule VibeBrains), и часть его контракта относится к
# возможностям, которых у нас нет и не планируется. Такой ключ — названная граница, а не пропажа;
# всё остальное, чего не читает ни один парсер, гейт валит.
#
# Гейт падает и на ключе вне списка, и на записи, которая больше ничего не находит: исключение,
# переставшее быть нужным, — такой же долг, как забытое мёртвое поле.

toolFormat|Формат объявления инструментов для модели. Прямой чат с моделью инструменты НЕ ШЛЁТ вовсе (проверено: в LlmClient нет ни "tools", ни "tool_choice") — их исполняет внешний ACP-агент, который собирает свои запросы сам. Читать поле было бы нечем воспользоваться.
