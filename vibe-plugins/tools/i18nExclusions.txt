# Файлы, чьи русские строки НЕ являются интерфейсом и потому не считаются храповиком.
#
# Формат: <путь>|<сколько таких строк в файле>|<причина>
#
# Число обязательно, и оно — второй сторож. Исключение выдаётся ФАЙЛУ, а причина всегда про
# ЧАСТЬ файла: «преамбулы уходят в промпт», «регэкспы детектора». Пока в файле лежит только это,
# всё честно; первая же строка интерфейса, попавшая туда позже, укрывается чужим обоснованием и
# не видна никому. Так уже было дважды: вынос DesignPhrases из DesignStyleRules освободил ~29
# непереведённых интерфейсных строк, а PipelinesFile прятал 11 сообщений загрузки под причиной
# про преамбулы ролей (10.09.2026).
#
# Поэтому число сверяется при каждом прогоне: разошлось — гейт падает и просит объяснить, что
# прибавилось. Прибавилась строка интерфейса — её место в каталоге; прибавились данные — правьте
# число вместе с причиной, осознанно. Ноль означает, что исключать больше нечего: исключение
# мёртвое, и его надо удалить (так нашлось CodeGraphBuilder.kt — «факт» там остался только в
# KDoc, а сам литерал живёт в CodeGraphStore).
#
# Правило приёма строгое: сюда попадает только то, что человек никогда не увидит на экране.
# Сообщение находки, подпись кнопки, текст ошибки в ленте — интерфейс, сколько бы их ни было.
