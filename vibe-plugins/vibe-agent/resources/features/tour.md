# Что умеет VibeIDEA

Список того, что уже встроено и чаще всего остаётся ненайденным. Каждая строка говорит, **где это
включается или вызывается**: действия ищутся через «Найти действие» (⇧⌘A / Ctrl+Shift+A) по имени.

## Интерфейс

- **Плотный интерфейс** — верхняя полоса, вкладки и заголовки панелей тоньше. Включён у нас по
  умолчанию, выключается штатно: View → Appearance → Compact Mode. Настройка платформенная, наше
  умолчание применяется один раз и потом не спорит с вашим выбором.
- **Тонкие скроллы во всей IDE** — полосы прокрутки шириной 4 px вместо штатных. Толщина
  настраивается: Settings → Tools → VibeIDEA → Интерфейс (`0` возвращает обычные полосы).
- **Тема Vibe Neon Dark** — Settings → Appearance → Theme.

## Агент

- **Панель «Агент»** — чат с агентом по проекту: вкладки, история, прикреплённые файлы, режимы.
- `Vibe.RecordDecision` — **зафиксировать решение проекта**: вопрос, выбор, отвергнутое и почему.
  Записывается файлом в `docs/decisions/` и подаётся агенту, когда тема всплывёт снова. Быстрее —
  ссылка «решение» под ответом агента.
- `Vibe.Ingest` — **положить документ в корпус**: внешний PDF или текст остаётся в проекте, а не
  живёт одну сессию.
- `Vibe.Doctor` — **диагностика**: сборка, провайдеры, конфиги, индексы, состояние корпуса — одним
  отчётом.
- `Vibe.SpendReport` — **куда ушли токены** за сутки и за неделю; `Vibe.SpendExport` — то же
  таблицей.
- `Vibe.Breakers` — **предохранители**: что остановило агента и почему.
- `Vibe.SkillsCatalog` — **навыки проекта** (`.vibe/skills`), `Vibe.ValidateSkills` — проверка их
  формата.
- `Vibe.ProjectCommands` — **команды проекта** из `.vibe/commands.json`.
- `Vibe.ShowChatHistory` — **прошлые чаты**, поиск по транскриптам.

## Документация и знания

- `Vibe.DocsReport` — **связность документации**: недостижимые страницы и ссылки в никуда.
- Панель **«Документы»** — markdown проекта как граф, а не как список файлов.
- **Библиотекарь** работает молча: перед ходом агенту называются подходящие записи базы знаний,
  принятые решения и документы корпуса.

## Языки

- **TypeScript/JavaScript, PHP, CSS, ESLint** — через языковые серверы; сами серверы ставятся на
  машину, а не поставляются нами (лицензии и размер).
- `Vibe.LspDoctor` — **что установлено, чего нет и одна строка установки**.
- **Отладка** JavaScript/TypeScript и PHP (Xdebug) — через штатные адаптеры отладки.

## Дев-стек и превью

- Панель **«Vibe Server»** — сервисы и задачи с зависимостями и проверками готовности
  (`.vibe/servers.json`). **Файла нет** — дев-сервер угадывается по `package.json`, а кнопка
  «Создать файл» запишет его.
- Кнопка **«Превью»** — страница сервиса во встроенном браузере IDE.
- Панель **«Дизайн»** — встроенный браузер: размеры экрана, измерение страницы по 81 правилу,
  QR-адрес для телефона, ошибки страницы в чат.

## Базы данных и HTTP

- Панель **«БД»** — подключения из `.vibe/dataSources.json`, дерево схем, консоль, выгрузка CSV,
  **правка данных по первичному ключу**, подсказки SQL по схеме (Ctrl+Space в консоли).
- Панель **«HTTP»** — запросы файлами `.http` в репозитории, окружения, история ответов, cookies,
  cURL в обе стороны, генерация из OpenAPI.

## Внешние связи

- **MCP-сервер** — внешний агент видит граф импортов, проект, решения и может поставить задачу.
  `Vibe.ShowApiToken` — токен, `Vibe.RegenerateApiToken` — сменить.
- **Мост в Telegram** — `Vibe.TelegramToken`.
