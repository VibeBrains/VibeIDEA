# Языковой файл VibeIDEA — спецификация

> **Как этим пользоваться.** Скопируйте весь этот файл целиком своей LLM и попросите:
> *«По этой спецификации переведи каталог строк VibeIDEA на <язык> — вот содержимое `en.json`»*.
> Документ самодостаточный: всё, что нужно для корректного файла, ниже.

---

## 1. Где лежит

```
~/.vibe/lang/<код языка>.json
```

`<код языка>` — две-три латинские буквы, при необходимости с регионом: `en`, `de`, `pt-br`, `qya`.
Имя файла и есть код: нашёлся файл — язык появился в списке выбора, удалили — исчез.

Базовый язык (русский) **вкомпилирован в приложение** и файлом не поставляется. Он же служит
подложкой: ключа нет в переводе — показывается базовая строка. Половина перевода уже работает.

## 2. Формат

Объект JSON, ключ → строка. Ничего вложенного.

```json
{
  "runs.filter.all": "All",
  "design.action.measure": "Measure",
  "runs.summary": "Runs: {total} · running {running} · finished {completed}"
}
```

| Правило | Почему так |
|---|---|
| Ключи **плоские точечные** (`design.status.picked`) | вложенность красивее в редакторе и хуже во всём остальном: частичный перевод, диффы, поиск по коду, объяснение формата модели |
| Ключи **не переводятся и не меняются** | по ним приложение находит строку |
| Значения — только строки | всё остальное игнорируется |
| Кодировка UTF-8 | — |
| Неизвестный ключ | игнорируется (и ловится гейтом при разработке) |

## 3. Подстановки

Именованные: `{count}`, `{path}`, `{url}`.

- Порядок слов в языках разный — **двигайте скобку куда нужно**;
- **не переименовывайте и не удаляйте** её: имя это контракт с кодом;
- значение не пришло — на экране остаётся видимый `{count}`. Так и задумано: видимая скобка
  называет ошибку, а молчаливое удаление её прячет.

Пример правильного переноса:

```
ru: "Прогонов: {total} · работают {running}"
en: "Runs: {total} · running {running}"
de: "{total} Läufe · {running} aktiv"
```

## 4. Разметка

В подсказках настроек допустимы простые теги — `<code>`, `<b>`, `<html>` в начале строки, если они
есть в оригинале. Переводите текст, теги оставляйте на месте.

## 5. Что происходит при запуске

1. Папка читается **один раз** при старте и живёт в памяти. Удаление файлов под работающей IDE
   ничего не ломает, и ни одна подпись не ждёт диска.
2. Выбирается язык: сохранённый в настройках → системный → базовый. Сохранённый язык, файл
   которого исчез, откатывается автоматически и пропадает из списка — предлагать выбрать то, чего
   нет, значит показать пустой интерфейс.
3. Строки сливаются один раз: перевод поверх базы. Слияние делает одна сторона, поэтому две
   половины приложения не могут разойтись в том, как называется кнопка.

## 6. Проверка перевода

- В интерфейсе не должно остаться видимых `{…}` — это незакрытая подстановка.
- Пустая строка означает пустую подпись: если перевода нет, **удалите ключ**, тогда покажется
  базовая строка.
- Строки длиннее оригинала обрезаются не всегда — проверьте кнопки и статусы глазами.

## 7. Файл базового языка

Его нет в папке намеренно: файл всегда сильнее бинаря, и засеянная копия навсегда заморозила бы
сегодняшние формулировки — исправленная опечатка ушла бы в новую версию и осталась бы перекрыта
старым файлом.

Нужна правка базовых строк — Settings → Tools → VibeIDEA → Интерфейс → «Создать файл базового
языка для правки»: тогда перекрытие осознанное.
