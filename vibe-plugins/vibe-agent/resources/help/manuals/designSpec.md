# Спека: дизайн-контекст (`.vibe/design/`)

> Скопируйте этот файл целиком своей LLM и попросите собрать файлы `.vibe/design/` под ваш продукт — этого документа достаточно. (У VibeIDE такой спеки не было — формат жил в коде; здесь мы закрываем этот долг.)

## Что это

Четыре обычных markdown-файла — дизайн-память проекта. Принадлежат вам, правятся руками; отсутствующий файл — тишина, не ошибка. Когда хоть один существует, панель Vibe Agent автоматически подмешивает агенту **пути** к ним (не содержимое — агент читает нужное сам), с порядком подачи: uiKit первым («это уже есть?» — раньше палитры).

| Файл | Fallback в корне | Что внутри |
|---|---|---|
| `.vibe/design/uiKit.md` | `ui-kit.md`, `UI-KIT.md` | карта построенного: таблица «Слой → Файл → Что внутри», имена в обратных кавычках (`Button`, `--color-accent`); пополняется по факту промаха, не впрок |
| `.vibe/design/components.md` | `COMPONENTS.md` | памятки по видам компонентов (заголовок = вид: «Форма», «Таблица»…); пустое тело = заготовка, пропускается; читается ДО постройки нового |
| `.vibe/design/design.md` | `DESIGN.md` | визуальный мир: палитра (hex), гарнитуры (в обратных кавычках), именованные правила, раздел «Детектор» с осознанными отклонениями |
| `.vibe/design/product.md` | `PRODUCT.md` | стратегия: для кого конкретно («основатель-одиночка с телефона», не «пользователи») и что продукт делает возможным |

## Форматы, которые разбираются автоматически

- **Именованное правило** (в design.md): строка вида `**Воздух дороже плотности.** Отступы между блоками не сжимать ради влезания.` — жирный зачин с точкой делает правило цитируемым в споре.
- **Осознанное отклонение** (в design.md, под заголовком «Детектор» / «Осознанные отклонения»): `- rule-id — причина`. Принятая находка не исчезает — печатается как осознанная, с причиной.

## Пример design.md

```markdown
# Визуальный мир

## Палитра
Фон `#16171B`, акцент `#00E5FF`, опасность `#FF2E97`.

## Типографика
Основная гарнитура `Inter`, код — `JetBrains Mono`. Кегли: 13/15/20/28.

## Именованные правила
**Один акцент на экран.** Неоновый циан — только у главного действия.
**Воздух дороже плотности.** Отступы не сжимать ради влезания.

## Детектор
- color-accent-overuse — неон в бренд-шапке принят как идентичность
```

## Чего в этом срезе нет (честные границы)

Живой замер со страницы, 81 детерминированный детектор, два вьюпорта, оверлей и enforceFloor-хук — часть браузерного движка (JCEF + мост), он в очереди (roadmap №16); правила-детекторы — чистые функции над JSON-снимком и портируются позже без переделки контракта этих файлов.
