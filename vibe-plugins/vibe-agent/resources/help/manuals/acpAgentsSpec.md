# Спека: реестр ACP-агентов (`~/.jetbrains/acp.json`)

> Скопируйте этот файл целиком своей LLM и попросите собрать `acp.json` под ваших агентов — этого документа достаточно, в интернет и исходники ходить не нужно.

## Что это

Реестр локальных AI-агентов для панели **Vibe Agent** в VibeIDEA. Формат совместим с интеграцией ACP в JetBrains IDE — один файл работает и там, и там. Агент — это локальная программа, говорящая по Agent Client Protocol (JSON-RPC 2.0 через stdin/stdout).

## Чей счёт оплачивает работу

Агент — **ваша** программа на **вашей** машине с **вашей** учётной записью: VibeIDEA не проксирует
запросы и не участвует в биллинге. Для Claude Code это значит, что работа идёт с лимитов вашей
подписки Anthropic — включая запуск из стороннего приложения через Agent SDK
([справка Anthropic](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan):
«Claude Agent SDK, `claude -p` и usage сторонних приложений по-прежнему списываются с лимитов
подписки»).

**Состояние временное, а не окончательное.** Anthropic 15.06.2026 **приостановила** объявленное
разделение: планировались отдельные месячные кредиты $20–$200 на тарифы, не покрывающие
интерактивный Claude Code, веб- и мобильный чат. Пауза — не отмена, и продакшен-нагрузку сам
Anthropic предлагает вести по API-ключу с оплатой по факту, а не с подписки. Если разделение
включат, изменится не наш код, а то, откуда списывается ваш usage.

## Где лежит

`~/.jetbrains/acp.json`. Файла нет — VibeIDEA предлагает агентов по умолчанию (Claude Code через адаптер `@agentclientprotocol/claude-agent-acp`). Файл есть — берутся записи из него.

## Формат

```json
{
  "agent_servers": {
    "Claude Code": {
      "command": "npx",
      "args": ["-y", "@agentclientprotocol/claude-agent-acp"],
      "env": { "ANTHROPIC_API_KEY": "sk-..." }
    },
    "Cursor Agent": {
      "command": "agent",
      "args": ["acp"]
    },
    "Gemini CLI": {
      "command": "gemini",
      "args": ["--experimental-acp"],
      "env": {}
    }
  }
}
```

- **Ключ записи** — отображаемое имя агента (любая строка).
- **command** — исполняемый файл. Ищется в PATH и типовых каталогах (`/opt/homebrew/bin`, `/usr/local/bin`, `~/.local/bin`, `~/.npm-global/bin`) — GUI-приложениям macOS shell-PATH не достаётся. Можно абсолютный путь.
- **args** — список аргументов (массив строк, может быть пустым или отсутствовать).
- **env** — переменные окружения поверх системных (объект строка→строка, может отсутствовать).

## Правила

- Агент запускается **без оболочки**: `command` + `args` как есть, никакой интерпретации `;`, `|`, `$VAR`.
- Битая запись (нет `command`, неверный тип) **пропускается с предупреждением** в чате — остальные работают.
**Cursor Agent говорит по ACP сам** — адаптер не нужен. Бинарь называется `agent` (ставится вместе
с приложением Cursor, обычно `~/.local/bin/agent`), подкоманда — `acp`; ключ передаётся флагом ДО
подкоманды (`agent --api-key … acp`), либо достаточно один раз выполнить `cursor login`. Режимы
`agent` / `plan` / `ask` — это штатные режимы сессии ACP, они появляются пикером над композером.
MCP-серверы он берёт из `.cursor/mcp.json` (проектный и пользовательский); **серверы уровня
команды из дашборда Cursor в режиме ACP не подхватываются** — источник:
[cursor.com/docs/cli/acp](https://cursor.com/docs/cli/acp), проверено 08.09.2026.

## Что клиент объявляет о себе

Возможности объявляются **явно**, и это не формальность: по спеке ACP агент не шлёт того, о чём
клиент не сказал. VibeIDEA объявляет чтение и запись файлов, терминал (когда запуск команд
разрешён настройкой), `elicitation` в обоих режимах (форма и URL) и `session.configOptions.boolean`
— тумблеры конфигурации агента, которые в v1 включаются только явным согласием клиента.

Версия протокола — **1**. Черновик v2 (20.07.2026) ломает почти всё, что мы используем
(capabilities сливаются в один объект, режимы сессии переезжают в configOptions, `session/load`
заменяется на `session/resume`, клиентские ФС и терминал убираются), автоматической конверсии
v1↔v2 не планируется — поэтому v1 остаётся рабочей целью, а версия названа одной константой
(решение №50).

- Секреты в `env` видны любому, кто прочтёт файл — храните файл с правами 600; лучше давать агенту логиниться самому (Claude Code использует свой сохранённый логин, ключ в env не обязателен).

## Проверка

Открыть тулвиндоу «Vibe Agent» → выбрать агента → написать сообщение. Первое сообщение запускает процесс и открывает сессию; ошибки запуска печатаются в чат с именем недостающего бинаря.

## Секреты в `env`

Значения `env` понимают `${secret:ИМЯ}`: подстановка происходит при старте агента из хранилища ОС (`.vibe/.env`, затем переменные окружения). Токен при этом не лежит в `acp.json`, который едет вместе с репозиторием.

Ограничение, которое стоит знать: дочерний процесс живёт с тем окружением, с которым его запустили, поэтому подставленное значение доступно агенту всё время его жизни. Сузить это окно можно было бы только перезапуском агента на каждый вызов — то есть отказом от сессии, ради которой агент и держится.
