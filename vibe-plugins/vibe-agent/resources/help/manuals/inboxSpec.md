# Спека: входящее (`docs/inbox/`)

> Скопируйте этот файл своей LLM, если нужно собрать или разобрать документ корпуса вручную.

## Что это

Внешний документ, положенный **в проект**, а не прикреплённый к сообщению. Вложение живёт одну
сессию: через неделю тот же PDF прикрепляют снова, и агент читает его снова — за те же токены.
Документ корпуса остаётся: его находит библиотекарь, он попадает в код-ревью и в историю git.

## Как положить

Действие **«Положить документ в корпус»** (Help → Find Action). Выбирается файл, уже лежащий на
диске: **из интернета ничего не скачивается** — сеть без спроса это отдельное решение, которого мы
не принимали.

- **PDF** разбирается `pdftotext` (poppler; `brew install poppler` на macOS). Скан без текстового
  слоя **не кладётся**: документ, который существует и молчит, хуже отсутствующего — модель
  ответит по нему уверенно и мимо.
- Текстовый файл кладётся как есть.

## Формат

```markdown
# Договор с подрядчиком

> Пришло снаружи: `/Users/me/Downloads/contract.pdf`
> Добавлено: 2026-09-05
> Страниц в исходнике: 12
> Отрезано символов пределом: 4200

Стороны договорились…
```

Шапка — не украшение: документ без происхождения через месяц неотличим от нашего собственного
текста, и его начинают править как свой. Обрезание по пределу **называется**, а не прячется.

Рядом — обязательный индекс `README.md` со строкой на документ: без строки документа не существует.

## Границы

- Ссылки из интернета не тянем.
- OCR не делаем: распознавание скана — чужой инструмент и чужие данные, ставить его за пользователя
  мы не будем.
- Предел текста — тот же, что у вложений PDF (около 60 000 символов): документ, вытесняющий из
  контекста всё остальное, вреден молча.

## Как это видно в IDE

- **Библиотекарь** называет агенту подходящие документы по теме запроса — путями, а не текстом.
- **Диагностика** (действие «Диагностика») показывает число документов и **файлы без строки в
  индексе**: такой файл лежит на диске и не существует ни для библиотекаря, ни для человека,
  который ищет по индексу.

## Повторы и одинаковые заголовки

- Документ из **того же источника** узнаётся по строке происхождения в индексе: IDE спросит, нужна
  ли вторая копия, вместо того чтобы молча её завести.
- Два документа с **одинаковым заголовком** получают разные имена (`otchet.md`, `otchet-2.md`), и
  строка индекса ведёт на реальное имя. До ревизии 07.09.2026 второй документ молча затирал первый,
  а индекс при этом показывал обе записи — то есть корпус выглядел полным.
