# Языки интерфейса VibeIDEA

Эта папка — все языки, кроме базового. Базовый (русский) вкомпилирован в приложение и служит
подложкой: если в вашем файле ключа нет, показывается базовая строка, а не пустая кнопка. Поэтому
**половина перевода уже полезна** — можно переводить по частям.

## Как добавить свой язык

1. Скопируйте `en.json` в файл с кодом вашего языка: `de.json`, `fr.json`, `qya.json` — что угодно
   из двух-трёх латинских букв (можно с регионом: `pt-br.json`).
2. Переведите значения. **Ключи не трогайте** — по ним приложение находит строку.
3. Перезапустите IDE: папка читается один раз при старте.
4. Выберите язык: Settings → Tools → VibeIDEA → Интерфейс → «Язык интерфейса».

Удалили файл — язык исчезнет из списка, а интерфейс вернётся к базовому. Ничего не сломается.

## Правила формата

- **Плоские точечные ключи**: `runs.filter.all`, а не вложенные объекты. Так проще искать по коду,
  видеть диффы и переводить частями.
- **Именованные подстановки**: `{count}`, `{path}`. Порядок слов в языках разный — двигайте скобку
  куда нужно, но **не переименовывайте** и не удаляйте: подстановка это часть контракта.
  Если значение не пришло, на экране останется видимый `{count}` — это признак ошибки в коде,
  а не мусор в вашем переводе.
- Разрешена простая html-разметка в подсказках (`<code>`, `<b>`) — там, где она есть в оригинале.
- Кодировка UTF-8, значения — строки. Всё, что не строка, игнорируется.

## Файл базового языка

Его здесь нет намеренно. Файл всегда сильнее бинаря, поэтому засеянная копия базового языка
навсегда заморозила бы сегодняшние формулировки: исправленная опечатка попала бы в новую версию
приложения и осталась бы перекрыта вашим старым файлом.

Если правка базовых строк всё-таки нужна — Settings → Tools → VibeIDEA → Интерфейс →
«Создать файл базового языка для правки». Тогда перекрытие осознанное, и вы знаете, что делаете.

## Пример

```json
{
  "runs.filter.all": "All",
  "runs.summary": "Runs: {total} · running {running} · finished {completed}",
  "design.action.measure": "Measure"
}
```
