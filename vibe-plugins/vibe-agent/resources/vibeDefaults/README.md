# .vibe — окружение проекта для VibeIDEA

Эта папка — конфигурация агентской обвязки VibeIDEA для ЭТОГО проекта.
Создана автоматически; всё в ней опционально. Файлы `*.example.jsonc` — образцы:
скопируйте нужный в файл без `.example` (строгий JSON, без комментариев) — и он заработает.

| Файл | Что включает |
|---|---|
| `hooks.json` | Команды проекта вокруг действий агента (запрет/линт/тесты). Включается в Settings → Tools → VibeIDEA → Агент |
| `pipelines.json` | Цепочки шагов-ролей (планировщик → разработчик → ревьюер) |
| `servers.json` | Дев-стек: волны запуска, readyCheck, зависимости |
| `providers/` | Каталог LLM-провайдеров для прямого чата — читается автоматически, тумблер `active`; `providers.json` (опционально) накладывается поверх |
| `rules.md` | Правила проекта для агента (подтягиваются через `@agent`) |
| `design/` | Дизайн-контекст: uiKit.md и components.md подмешиваются агенту при работе с UI |

Рядом появляются рабочие журналы (`checkpoints.jsonl`, `audit.jsonl`) — они
в `.gitignore` этой папки и в git не попадают.

Полные спеки форматов (можно скормить любой LLM): docs/vibe/manuals/*Spec.md
в репозитории VibeIDEA, либо попросите агента в чате: «создай мне .vibe/hooks.json».
