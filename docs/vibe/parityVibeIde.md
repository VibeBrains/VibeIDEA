# Паритет с VibeIDE: что уже умеет VibeIDEA и чего ей не хватает

**Сверка:** 2026-08-30 · **Источник:** [VibeIDE `docs/functional.md`](https://github.com/VibeBrains/VibeIDE/blob/main/docs/functional.md)
(локальный клон `main @ 01a2d6892`, с origin/main расхождений нет) · **Наша сторона:** проверялась по коду, а не по документации.

Цель — не переписать VibeIDE на Kotlin, а закрыть разрыв там, где он **ощущается в работе**. Часть
возможностей VibeIDE — обход ограничений VS Code, которых у платформы IntelliJ нет: их переносить не
нужно, и они отмечены как «платформа даёт».

Легенда: ✅ есть · 🟡 частично (сказано, чего именно недостаёт) · ❌ нет · ⬜ переносить не нужно.

## 🧠 AI-ядро

| VibeIDE | VibeIDEA | Разрыв |
|---|---|---|
| Роутер LLM-провайдеров | ✅ | `providers.json`, стриминг openai+anthropic |
| Свои провайдеры файлами, 4 уровня | ✅ | каталог + `providers.json`, глобальный и проектный |
| Локальные модели: автодетект и онбординг | 🟡 | описать Ollama в `providers.json` можно; **автодетекта и онбординга нет** |
| FIM-автокомплит | ✅ | + кэш, фильтры, метрики |
| Инлайн-правка Ctrl+K со слэш-командами | ❌ | нет ни инлайн-правки, ни `/doc /refactor /tests /explain /fix` |
| Индексация и семантический поиск (RAG) | ❌ | у нас граф импортов + PSI-поиск платформы, но не RAG |
| Справка о продукте внутри сборки | ❌ | агент не может прочитать наши доки из дистрибутива |
| `code_graph` | ✅ | с происхождением рёбер (факт/догадка) |
