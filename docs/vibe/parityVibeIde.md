# Паритет с VibeIDE: что уже умеет VibeIDEA и чего ей не хватает

**Сверка:** 2026-08-30, обновлена в тот же день по итогам переноса · **Источник:** [VibeIDE `docs/functional.md`](https://github.com/VibeBrains/VibeIDE/blob/main/docs/functional.md)
(локальный клон `main @ 01a2d6892`, с origin/main расхождений нет) · **Наша сторона:** проверялась по коду, а не по документации.

Цель — не переписать VibeIDE на Kotlin, а закрыть разрыв там, где он **ощущается в работе**. Часть
возможностей VibeIDE — обход ограничений VS Code, которых у платформы IntelliJ нет: их переносить не
нужно, и они отмечены как «платформа даёт».

Легенда: ✅ есть · 🟡 частично (сказано, чего именно недостаёт) · ❌ нет · ⬜ переносить не нужно.
