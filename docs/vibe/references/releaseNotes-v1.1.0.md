## Что это

**VibeIDEA — открытая IDE PhpStorm-класса со встроенным агентом.**
Форк [intellij-community](https://github.com/JetBrains/intellij-community): платформа JetBrains, языки через LSP, вся агентская обвязка своя.

Этот выпуск делает работу с внешним агентом дешевле по токенам и добавляет агенту глаза и уши: он сам разбирает видео и аудио.
Ещё в нём настоящее слияние файлов `.vibe` и несколько исправлений ленты чата.
Ставится поверх 1.0.0.

---

## Агент тратит меньше токенов

**Контекст проекта уходит внешнему агенту один раз на сессию, а не с каждым сообщением.**

- К каждому сообщению приклеивались правила проекта, указатели знаний, дизайн-контекст и минимализм.
  На одном ревью через Claude Code это давало около 9,4 тысячи токенов на сообщение и +39 % к расходу.
- Агенту, который читает инструкции сам, IDE передаёт только своё: правила `.vibe/rules` и `.cursor/rules` и указатели.
  Файлы `CLAUDE.md`, `AGENTS.md` и правила пользователя он читает сам, и дублировать их незачем.
- Правка правил посреди сессии уходит агенту один раз.
- Метки чужой сессии Claude Code и `CLAUDE_CODE_SIMPLE` агенту больше не передаются.

## Агент смотрит видео и слушает аудио

- У модели появился инструмент `vibe_watch_media`: транскрипт и кадры с тайм-кодами, тот же конвейер, что у команды `/watch`.
- Работает в прямом чате, в ролях и у внешнего агента ACP.
- У локального файла нет дорожки субтитров, поэтому речь распознаёт движок голосового ввода.
  Локальное аудио больше не упирается в отказ.
- Фразы вроде «посмотри видео», «разбери ролик», «расшифруй запись», «разбери созвон» включают правило из общего набора сами.
- Путь можно писать от корня проекта (`1.webm`, `sub/2.webm`), от домашней папки (`~/…`) или абсолютным; ненайденный файл назван по имени и корню.
  Команда `/watch` принимает путь в кавычках.

## Слияние файлов `.vibe`

- Кнопка «Смержить» в уведомлении «релиз обновил N файлов» открывала только просмотр, в котором нельзя было ничего применить.
  Теперь это штатный диалог слияния IDE: «Принять ваше», «Принять релиз» и ручное слияние на три панели.
- Слева ваш файл, справа файл из релиза, а в основе — ревизия, от которой он был засеян.
  Для проектов без сохранённой основы она пуста, и заголовок окна об этом говорит.
- Уведомление гаснет, когда решены все файлы.

## Чат

- **Ответ агента не теряет текст**: звёздочки в `src/*.kt` и `2 * 3 * 4` больше не превращаются в курсив, скобки вида `arr[0](1)` остаются как написаны, код во вложенном списке с отступом в четыре пробела и больше показывается блоком.
- Список прошлых чатов на пустом чате прокручивается в границах панели, а «Свернуть» стоит над ним.
- Выделение у края ленты прокручивает её, Shift+клик продолжает выделение.
- Карточка терминала сворачивается и тогда, когда команда ушла в фон и не вернула код выхода.
- Когда окно IDE не в фокусе, вопрос о разрешении и форма показывают уведомление «Vibe Agent ждёт ответа».

## Правила, секреты, MCP

- Списки `globs` и `triggers` в шапке правил разбираются правильно: запятая внутри кавычек и скобок не делит список, `{a,b}` в glob раскрывается.
  Правило `ui-kit` из общего набора раньше не срабатывало ни на одном файле.
  Принимается и псевдоним `@rule:имя`.
- Нерешённая ссылка `${secret:ИМЯ}` в `env` внешнего агента больше не уходит ему текстом: переменная не задаётся, а в журнале протокола предупреждение с именами переменной и секрета без значений.
- Отпечаток инструментов MCP больше не принимает перестановку слов за подмену: сервер, отдающий список в другом порядке, не помечается «изменённым» после каждого запуска.
  Одобрения в старой форме принимаются.
- MCP-серверы со списком разрешённых инструментов (`tools`) не передаются внешнему агенту: он этот список не соблюдает и увидел бы все инструменты сервера.
  В ленте об этом одна строка с именами серверов.

## Установка

**macOS (Apple Silicon):** `VibeIDEA-1.1.0-aarch64.dmg` — перетащить в «Программы».

```bash
shasum -a 256 VibeIDEA-1.1.0-aarch64.dmg
# __SHA256_DMG__
```

**Windows (x64):** `VibeIDEA-1.1.0.exe` — обычный инсталлятор; или `VibeIDEA-1.1.0.win.zip` — распаковать куда угодно и запустить `bin\idea64.exe`.

```powershell
Get-FileHash VibeIDEA-1.1.0.exe -Algorithm SHA256
# __SHA256_EXE__
Get-FileHash VibeIDEA-1.1.0.win.zip -Algorithm SHA256
# __SHA256_ZIP__
```

**Linux (x64):** `VibeIDEA-1.1.0.tar.gz` — распаковать и запустить `bin/idea.sh`.

```bash
sha256sum VibeIDEA-1.1.0.tar.gz
# __SHA256_TGZ__
```

**Что нужно на машине:** PHP 8.1+ и Node 18+.
Для отладки PHP — Xdebug.
Для базы — драйвер JDBC, его скачает кнопка в панели «БД».
Для общей памяти в чате — установленный VibeMemory.
Для голоса — модель распознавания: её предложит скачать кнопка микрофона.
Для голосовых сообщений через Telegram — ffmpeg.
Чтобы агент разбирал видео и аудио — ffmpeg.

**Обновление с 1.0.0:** ставится поверх.

## Чего пока нет

Сборка **не нотаризована** у Apple: macOS предупредит при первом запуске, Windows покажет SmartScreen.

**Живьём не проверено** (собрано, покрыто тестами, но руками не обкатано):

- разбор видео и аудио агентом: ни на реальном видео, ни на `.m4a` не гонялось; ссылка на аудио без субтитров не поддержана, а в `/watch` из композера корень берётся по последнему открытому проекту;
- диалог слияния `.vibe`: проверен компиляцией и тестами логики;
- передача контекста внешнему агенту раз на сессию: замер сделан до правки на одном ревью, повторный замер на живом агенте не делался;
- разметка ответа, список прошлых чатов, выделение у края ленты, фоновая команда в карточке терминала: в живой IDE не смотрели;
- голосовой ввод T-one: проверен на скриптовых декодерах, не на живом движке;
- сид Gemini 4 Argon: окно контекста и поддержку изображений страница вендора не называет, поля не заполнены;
- отпечаток MCP: проверен на векторах, не на сервере с перемешивающимся порядком;
- MiniMax-M3.1-Flash вместо Preview: что новое имя обслуживает прежняя модель, подтверждает только дайджест, а не страница вендора.

**Про Windows честно:** `.exe` собран здесь же, на macOS, и проверен по составу.
Тихой установкой на Windows он **не проверялся**.

**Про Linux честно:** артефакт собран здесь же и проверен по составу.
**На Linux он не запускался**: линуксовый лаунчер и JBR на маке выполнить нечем.

Обкатывает продукт один человек.
Если что-то ведёт себя не так — самый полезный [issue](https://github.com/VibeBrains/VibeIDEA/issues/new), который сейчас можно завести.
