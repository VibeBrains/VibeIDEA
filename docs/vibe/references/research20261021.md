Одна сводка за тринадцать дней вместо потерянных ежедневных, архив — [digest20261021catchup.md](digest20261021catchup.md).

## Что принёс дайджест

В самом дайджесте две неточности, а настоящий дрейф только один: адрес.
1. «Gemini 2.5 выведены 20.10» — страница changelog этого не говорит: с 18.09 доступ только прежним пользователям, «not deprecated», обслуживаются «until further notice»; вывели 3.7 Flash (08.10, перенаправление на 3.8).
2. «M3.1 Flash только по подписке» — устарело: модель есть в pricing-paygo ($0.15 / $0.60, кэш $0.015).
3. OpenCode: документация называет базой `https://opencode.ai/inference/go`; наш сид стоит на `…/zen/go/v1`, который на 21.10 ещё отвечает списком моделей.

## Не берём

- **CVE-2026-104850 (MCP TS SDK):** подтверждена (CVSS 7.5, версии 1.12.0–1.30.x, фикс 1.31.0), но у нас нет ни TS SDK, ни OAuth в MCP-клиенте: `McpHttpTransport` шлёт только Bearer с готовым токеном, поставляемые серверы `deps` пакета `@modelcontextprotocol/sdk` не тянут (решения №41, №53, №109).
- **Haiku 5.5:** уже сделано 08.10 (решение №131), правило причуд и сид на месте.
- **DeepSeek V4.1 Flash-1017:** имя прежнее (`deepseek-flash`), цена не менялась, правок не нужно.
- **Meta Muse Wonder / Spark Open, Mistral Large 4:** без API для нас или без провайдера в наборе (решение владельца 10.10).
- **GPT-6 Intelligent UI, Claude Code Review GA, JetBrains AI Assistant:** функции чужих клиентов.
- **ACP:** спека без изменений (v2 черновик, №50); версия адаптера `claude-agent-acp` в сиде не закреплена («`@agentclientprotocol/claude-agent-acp`» без версии), сверять нечего.
- **Платформа 2026.3 EAP 6/7:** тот же вывод, что 22.09: у `vibe-*` нет импортов вынесенных модулей; при подтягивании ветки 263 проверить `JnaLoader.load` и реализации `Sdk` поиском по коду — слухом не является, но и не сделано, пока базы 263 нет.
- **Слухи:** публикация весов M3.1 Flash 23.10 (только СМИ); рост цены Argon с 01.12 подтверждён страницей цен, а вот «M Plan Go $22, Build ×7.5/×12» — по сводке, не по странице вендора.
