## Что это

**VibeIDEA — открытая IDE PhpStorm-класса со встроенным агентом.**
Форк [intellij-community](https://github.com/JetBrains/intellij-community): платформа JetBrains, языки через LSP, вся агентская обвязка своя.

Вторая цифра поднялась, потому что в выпуске есть новые возможности, а не только исправления.
Правки агента теперь принимаются и отклоняются по одной, прямо в редакторе.
Проект показывается картой подсистем, голос расшифровывается локально, а страницы настроек «Модели» и «MCP-серверы» стали карточками.

---

## Разбор правок агента по одной

**Каждую правку агента можно принять или отклонить отдельно, не трогая остальные в том же файле.**

- В редакторе правка подсвечена, на ней кнопки «принять» и «отклонить», внизу панель разбора.
- Четыре клавиши: следующая правка, предыдущая, принять, отклонить.
- После решения IDE сама переходит к следующей правке — порядок перехода общий с VibeIDE.
- Список правок в чате остался быстрым путём: принять или отклонить всё разом.

## Чат и композер

- **Сообщения в ленте** оформлены тремя голосами и тремя ширинами, как в VibeIDE; подпись пузыря читается на любой теме.
- **Журнал служебных сообщений**: значок в шапке окна агента с бейджем непрочитанного.
  - Служебные строки IDE — провайдеры, ключи, хуки, конфиги — ушли из ленты в журнал.
  - В ленте остаётся то, что остановило ход, и ответы на набранные команды.
  - В журнале повторы свёрнуты в «×N», есть фильтр по категории и кнопка «Открыть настройку».
  - Журнал переживает перезапуск IDE.
- **Пауза перед повтором запроса** видна плашкой; «Стоп» прерывает ожидание.
- **Дата и время** у каждого сообщения.
- **Вкладки чата**: крестик закрывает вкладку, не прыгая по ряду; Delete, Backspace и средняя кнопка мыши тоже закрывают.
- **Меню режимов** с короткими именами («Правки» вместо «Правки без вопросов»); пояснение — в подсказке за значком «?».
- **Список моделей**: пользовательские модели помечены карандашом, подсказка называет файл, откуда модель взята.
- **Выбор пайплайна** — список под кнопкой ▷ с цепочкой шагов вместо диалога.
- **Ряд кнопок композера** не разваливается от длинного имени модели: сначала сжимается кнопка модели, перенос строки — последнее средство.
- **Быстрые настройки**: офлайн-режим ушёл в подменю, пункты встали к левому краю.
- **Команды агента** появились в меню «/», команда уходит первым словом запроса.

## Голосовой ввод

**Расшифровка идёт на вашей машине, без облака.**

- Встроено распознавание **sherpa-onnx**: каталог моделей, загрузка с вашего согласия, с процентами и проверкой SHA256.
- Во время речи текст растёт черновиком в поле ввода; в черновик по «стоп» ложится окончательный вариант и не отправляется сам.
- Модель whisper.cpp находится сама; Python-whisper без вашего согласия больше не запускается.
- Кнопка микрофона показывает состояния: слушает, расшифровывает, ошибка; запись сопровождают звуки, индикатор пульсирует по уровню голоса.
- Каждый обрыв голоса назван в ленте человеческим текстом; лимит записи — 180 секунд.
- Мост в Telegram теперь требует ffmpeg при любом движке расшифровки.

## Граф проекта

**Проект делится на подсистемы сам, без модели, по связям между файлами.**

- Вкладка «Граф проекта» открывается из меню мозга.
- Сначала карта подсистем; каждая подписана папкой, где лежит не меньше половины её файлов.
- Клик по подсистеме раскрывает её — до 400 самых связанных файлов; клик по файлу открывает его в редакторе.
- Поиск по имени, выбор подсистемы, фильтры «Извлечённые» и «Догадки».
- Рядом отчёт: главные файлы, редкие мосты между подсистемами, одинокие файлы.
- `/map` рисует подсистемы вместо папок верхнего уровня.
- Разбор понимает импорт `./x.js` как `x.ts`: на большом проекте на TypeScript связей стало 3743 вместо 25.

## Команды проекта и меню мозга

- **Кнопка «Команды»** в заголовке окна: закреплённые команды запускаются кликом, первые девять — клавишами `Ctrl+Shift+Alt+1…9`.
  - Вывод идёт в окно Run.
  - «Управление»: закрепить, править, удалить; если файла нет — создать из образца.
- **Формат `.vibe/commands.json` общий с VibeIDE**: `command`, `args`, `cwd`, `env`, `confirm`, `singleton`, `shell`, `terminal`.
  - Прежняя запись VibeIDEA читается как синоним.
- **Кнопка с мозгом**: действия IDE пятью группами, новые «Новый чат» и «Настройки VibeIDEA».
  - Меню помещается на экран ноутбука; длинные группы свёрнуты в подменю.
  - Приставка «VibeIDEA:» убрана из подписей.

## MCP

- **Страница «MCP-серверы»** в настройках: карточка на сервер со статусом, включение, правка, удаление, добавление и перезапуск.
- **Общий файл `~/.vibe/mcp.json`** для VibeIDEA и VibeIDE: два слоя, серверы проекта сильнее общих.
- **Свой сервер в `.vibe/mcp.json`** заменяет найденный сервер с тем же именем у ACP-агента.
- Сервер с изменённой записью теперь перезапускается, а не живёт со старой до смерти процесса.
- Инструменты, ждавшие подтверждения, после него возвращаются модели.
- Процесс, который запустился и не ответил, больше не остаётся висеть.

## Правила, навыки, пайплайны

- **Правила из `.vibe/rules/`** читаются рекурсивно; при совпадении с `.cursor/rules/` побеждает второй.
- **Ключ `triggers`** в правиле: правило подключается по фразам, а не всегда — в засеянном проекте постоянные правила стали короче примерно на четверть.
- Общий набор `.vibe` обновлён: новые навыки, хуки-детекторы, к одиннадцати навыкам добавлены эвалы.
- **Пишущие шаги волны** в пайплайнах работают каждый в своём рабочем дереве git, изменения возвращаются трёхсторонним слиянием.
- Ошибка в настройке шага — флаг не булевым значением — теперь названа по имени поля.
- Новая панель «Демо» собирает отчёты демонстраций.

## Модели и провайдеры

- **ChatGPT по подписке**: вход через браузер, ключ API не нужен, токены лежат в системной связке ключей.
- **Новые модели в каталоге**: Claude Sonnet 5.5 и Haiku 5.5, GPT-6.1 Sol, Kimi K3, MiniMax M3.1 Flash Preview.
- **Усилие рассуждения посреди разговора без потери кэша**: GPT-6 и Claude принимают сдвиг ползунка, не пересчитывая историю.
- **Вызов инструмента текстом** читается у любой модели: распознаётся 17 разметок разных семейств, а не только DeepSeek.
- **Прямой чат проходит те же проверки, что ход агента**, и при объективном провале передаёт работу более сильной модели; ручной вариант — `/cascade`.
- **Диагностика кэша Anthropic** называет причину промаха и число токенов.
- **Подмены модели** на стороне вендора собираются в сводку; запасная модель вендора названа в диагностике.
- Кредит вендора после отказа применяется на повторе запроса.
- **Модели-роутеры** `cloudflare/auto` и `openrouter/auto` не считаются подменой; цена берётся по модели, которая ответила.
- **Праздники вне пика** учитываются в цене по часу (`timeOfDay.offPeakDates`).
- Лента называет модели, которых не было в прошлом каталоге провайдера.
- Блок рассуждения уходит только тому вендору, который его выдал.
- Модель знает, кто она: рабочее место хода называет модель, её id и провайдера — раньше MiniMax называла себя Claude.

## Исправлено

- Чат после перезапуска IDE открывается внизу ленты, а не с самого начала.
- Агент ACP находит `npx` в IDE, запущенной из Finder: учитываются настройка Node, окружение оболочки входа и менеджеры версий nvm, fnm, volta, asdf, mise и Homebrew.
- Ошибка запуска агента написана по-русски, с кнопкой «Открыть настройки Node».
- Отозванный агентом вопрос закрывается, «Стоп» снимает висящие вопросы, строковый номер запроса больше не теряется.
- Файл команд из VibeIDE запускал программу без аргументов; команда со ссылкой на секрет отклонялась; команда из нескольких слов не запускалась.
- Меню мозга не обрезается снизу на небольшом экране.
- Старая ревизия сида, которую вернул git при смене ветки, обновляется.
- Журнал не показывает предупреждений без причины; строки не печатают служебные приставки и лишние `{имена}`.

## Установка

**macOS** — `.dmg` (Apple Silicon) или `.sit`.
**Windows** — инсталлятор `.exe` или архив `.win.zip`.
**Linux** — `.tar.gz`.

**Что нужно на машине:** PHP 8.1+ и Node 18+.
Для отладки PHP — Xdebug.
Для базы — драйвер JDBC, его скачает кнопка в панели «БД».
Для общей памяти в чате — установленный VibeMemory.
Для голоса — модель распознавания: её предложит скачать кнопка микрофона.
Для голосовых сообщений через Telegram — ffmpeg.

**Обновление с 0.8.0:** ставится поверх, настройки сохраняются.

## Чего пока нет

Сборка **не нотаризована** у Apple: macOS предупредит при первом запуске, Windows покажет SmartScreen.

**Живыми ключами не проверено:** новые модели и провода собраны по документации вендоров и покрыты тестами, но ответа настоящего вендора не видели.
Это же касается входа через ChatGPT и сдвига усилия посреди разговора.

**Руками пока не обкатано:** разбор правок по одной, голосовой ввод на Windows, загрузка моделей распознавания, запись в файл со страницы «MCP-серверы».

**Про Windows честно:** `.exe` собран здесь же, на macOS, и проверен по составу.
Тихой установкой на Windows он **не проверялся**.

**Про Linux честно:** артефакт собран здесь же и проверен по составу.
**На Linux он не запускался**: линуксовый лаунчер и JBR на маке выполнить нечем.

**Не перенесено из VibeIDE:** сравнение описаний одобренных инструментов и серверы MCP по адресу `url` — наш разбор читает только `command`.

Обкатывает продукт один человек.
Если что-то ведёт себя не так — самый полезный [issue](https://github.com/VibeBrains/VibeIDEA/issues/new), который сейчас можно завести.
