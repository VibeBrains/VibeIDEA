## 🧱 Что это

**VibeIDEA — открытая IDE PhpStorm-класса со встроенным агентом.** Форк
[intellij-community](https://github.com/JetBrains/intellij-community): платформа JetBrains, языки
через LSP, вся агентская обвязка своя.

Этот выпуск — про **память проекта** и про то, что перестало врать в редакторе.

---

## 🔴 Почему `.tsx` был красным

Открытый `.tsx` подчёркивался почти целиком: «148 ошибок» на файле, который компилируется без
единого замечания. То же самое происходило с обычным `.js` — на легаси-проекте счётчик показывал
589 ошибок.

Причина оказалась в одной строке нашего описания плагина: все расширения были объявлены языковому
серверу одним идентификатором `typescript`. Это не подпись, а указание, **каким парсером** открыть
документ, и под ним синтаксис JSX запрещён — каждый тег превращается в ошибку. Замерено на живых
файлах: `typescript` — 152 диагностики, `typescriptreact` — ноль; на `.js`-файле — 671 против 49
подсказок про неиспользуемые переменные.

Исправлено: четыре идентификатора, как в VS Code. Та же ошибка была у сервера ESLint, который вдобавок
**падал на каждом файле** («Cannot read properties of null») — он не получал настроек и поднимался
даже в проектах, где ESLint не установлен вовсе.

## 🧠 Проект начинает помнить решения

Код отвечает на вопрос «как сделано» и молчит о том, **что было отвергнуто и почему**. Через месяц
эта половина стирается у всех, а у агента раньше всех: он предложит вариант, который вы уже пробовали
и выбросили, — подробно, уверенно и за ваши токены.

- **Журнал решений** — файлы `docs/decisions/` с обязательной строкой индекса. Заголовок записи —
  **вопрос**, а не выбранный вариант: через полгода ищут по вопросу, который возник снова. Причина
  обязательна; без неё запись не отвечает на то, ради чего её открывают.
- Фиксируется одним движением: ссылка **«решение»** под ответом агента предзаполняет вопрос вашим
  сообщением, а выбор — текстом ответа.
- **Решение отменяется решением**, а не правкой старого: новая запись ссылается на предыдущую, та
  помечается в индексе и перестаёт подаваться агенту. Файл остаётся — он свидетельство того, что и
  почему решили тогда.
- **Входящее** — внешний PDF или текст остаётся в проекте с шапкой происхождения, а не живёт одну
  сессию. Скан без текстового слоя не кладётся: документ, который существует и молчит, хуже
  отсутствующего.
- Всё это находит библиотекарь и видит внешний агент — `vibe_corpus_search` ищет по знаниям,
  решениям и документам сразу.

## 👁 Интерфейс стал плотнее

Верхняя полоса, вкладки и заголовки панелей теперь тоньше — включён штатный **Compact Mode**
платформы. Умолчание применяется один раз: выключите — останется выключенным.

**«Возможности VibeIDEA»** (Help → Find Action) открывает вкладкой список того, что встроено и
**где это включается**: плотный интерфейс, толщина скроллов, правка данных в БД, подсказки SQL,
cookies, журнал решений, дежурные проверки, расход токенов. Повод — фраза владельца: «даже в родной
IDE я не знал, что это переключается».

## 🗄 База данных: данные можно править

Двойной щелчок по таблице — и ячейка редактируема, **если правка адресуема**: в выборке есть
первичный ключ. Правка копится в буфере, кнопка «Применить» сначала показывает готовые
`UPDATE … WHERE ключ` и только потом выполняет их **одной транзакцией**. Отказ называется причиной:
нет ключа, ключ пуст, столбец сам входит в ключ, подключение помечено `"readOnly": true`.

**Подсказки SQL по схеме** — Ctrl+Space в консоли: таблицы после `FROM`, столбцы упомянутых таблиц
в `SELECT`, псевдоним `u.` сужает список. Схема берётся из прочитанного дерева — в базу по нажатию
клавиши не ходим.

## 🌐 HTTP и стек

- **Cookies** — вкладка со списком: вход кладёт сессию в куку, без неё второй запрос отвечает 401, и
  раньше причина не была видна нигде.
- **Vibe Server больше не бесполезен без файла**: дев-сервер угадывается по `package.json`, а кнопка
  «Создать файл» записывает догадку. Порт при этом не выдумывается — адрес берётся из того, что
  напечатал сам сервер.
- **Кнопка «Превью»** открывает страницу сервиса во встроенном браузере IDE.
- **Дежурные проверки** (`.vibe/patrols.json`) — дешёвая команда по расписанию решает, есть ли повод
  звать модель. Модель сама не зовётся: приходит уведомление с кнопкой.

## 💸 Деньги перестали врать молча

- **Срок годности цены** (`priceValidUntil`): промо кончаются вдвое и по расписанию, а записанная
  цена продолжает считаться как ни в чём не бывало. Теперь диагностика предупредит, а отчёт о
  расходе пометит суммы.
- **Смета до запуска пайплайна** — по вашему же журналу: сколько эти роли стоили в прошлые прогоны.
  Роль без истории называется отдельно и в сумму не входит.
- **Часовой кэш промпта** (`cacheTtl: "1h"`) — для сессий с паузами дольше пяти минут.
- **Рассуждение модели видно**: раньше рассуждающая модель молчала ровно столько, сколько думала, и
  это выглядело как зависание.

## 📦 Установка

**macOS (Apple Silicon):** `VibeIDEA-0.4.2-aarch64.dmg` — перетащите приложение в «Программы».

Сборка **не подписана и не нотаризована**: при первом запуске macOS покажет «Файл не может быть
открыт». Нажмите **«Готово»**, затем Системные настройки → Конфиденциальность и безопасность →
пролистайте вниз, там появится **«Открыть всё равно»**. Либо снимите карантин командой:

```bash
xattr -dr com.apple.quarantine /Applications/VibeIDEA.app
```

Проверить, что скачался наш файл:

```bash
shasum -a 256 VibeIDEA-0.4.2-aarch64.dmg
# d4cb1cb50d1313b69f81aefb537aca865d540a95af19c92a6315bcb268e0465d
```

**Что нужно на машине:** PHP 8.1+ и Node 18+. Для отладки PHP — Xdebug. Для базы — драйвер JDBC,
его скачает кнопка в панели «БД».

**Windows (x64):** `VibeIDEA-0.4.2.exe` — обычный инсталлятор; или `VibeIDEA-0.4.2.win.zip` —
распаковать куда угодно и запустить `bin\idea64.exe`.

Сборка **не подписана**: SmartScreen покажет «Система Windows защитила ваш компьютер» —
**«Подробнее»** → **«Выполнить в любом случае»**. Касперский может удалить `idea64.exe` по
поведению (`PDM:Trojan.Win32.Generic`): это детект неподписанного новичка, а не находка в файле.

Проверить, что скачался наш файл (PowerShell):

```powershell
Get-FileHash VibeIDEA-0.4.2.exe -Algorithm SHA256
# a389f32018cadbf791a6b68adcfc9964df6835cf8a3ceaa08ce3a8325e587d99
Get-FileHash VibeIDEA-0.4.2.win.zip -Algorithm SHA256
# 1c62488fbf72884ae993f7808efa9bd2706b8cde19290fef220b6ecc85ece40b
```

Требования те же, что у macOS: Node 18+ для TypeScript, CSS, ESLint и обоих адаптеров отладки;
PHP 8.1+ и Xdebug — для PHP. Встроенный PHP-сервер на Windows запускается — проверено запуском
собранного дистрибутива.

**Обновление с 0.4.1:** ставится поверх, настройки сохраняются. **Плотный интерфейс включится сам**
— выключается в View → Appearance → Compact Mode.

## 🚧 Чего пока нет

- **Подсветка синтаксиса SQL** в консоли базы — сейчас обычный текст.
- **Подпись сборки** — нужны учётные записи разработчика Apple и сертификат для Windows.
- Мастера OAuth, gRPC и WebSocket в HTTP-клиенте — намеренно вне плана.

## 🔬 Честно о зрелости

1530 тестов и **пять** гейтов исходников: пятый появился в этом же выпуске, когда сборка
инсталлятора упала на зависимости, которую не видели ни тесты, ни четыре прежних гейта.

Обкатывает по-прежнему один человек. Журнал решений, дежурные проверки и правка данных в БД **в
живой работе не обкатаны**. Если у вас не сработает — это самый полезный
[issue](https://github.com/VibeBrains/VibeIDEA/issues/new), который сейчас можно завести.
