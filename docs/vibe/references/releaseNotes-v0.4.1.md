## 🐘 PHP на Windows: обещание 0.4.0 выполнено

В 0.4.0 мы написали, что встроенный Phpactor запускается везде. **На Windows он не запускался.**

Проверок в его phar оказалось две: одна у сборщика Box, вторая — собственная, в самом
`bin/phpactor`. Мы гасили первую, а падала вторая, до первой дело просто не доходило. Проверка на
macOS увидеть этого не могла по построению: она отключала *функции* `posix_*`, а вторая проверка
спрашивает про *расширение* целиком — эмулировалось не то условие.

Теперь рядом с phar едет маленький лаунчер, который поднимает Phpactor напрямую, минуя обе
проверки и не трогая чужой код. **Снято запуском на Windows 11**, а не рассуждением.

## 🌐 HTTP-клиент: история и прогон всего файла

- **История ответов** — вкладка рядом с телом и заголовками: десять последних ответов запроса со
  временем, статусом и размером. Отдельной строкой сообщается **только изменение** — статус или
  тело; «вчера работало» и есть тот вопрос, ради которого в историю заглядывают.
- **«Прогнать всё»** — дымовой проход по файлу. Успехом считается только 2xx, упавшие называются
  поимённо, а изменяющие запросы (`POST`, `DELETE`) называются **до** прогона и требуют
  подтверждения: пять прогонов `POST /users` — это пять пользователей.

## 🗄 База данных: строку можно забрать

Правая кнопка на строке результата — **JSON** (в тикет), **INSERT** (повторить на другом стенде),
**WHERE** (найти её снова). `NULL` в JSON становится `null`, а не строкой; идентификатор `007`
остаётся строкой и не теряет нули; апостроф в `INSERT` удваивается; в `WHERE` пустое значение
сравнивается через `IS NULL`, потому что `= NULL` не истинно никогда.

## 🈯 JavaScript: IDE сама ставит диагноз

Открыли `.js` в большом проекте без `jsconfig.json` — приходит уведомление с кнопкой **«Создать»**.
Без этого файла языковой сервер видит только открытый файл и то, что достижимо через `import`:
в кодовой базе со своим загрузчиком классов (ExtJS, глобалы в `window`) переход к определению
молчит, и выглядит это как «IDE не умеет», хотя это отсутствующий файл на десять строк. В
`include` попадают каталоги вашего кода, в `exclude` — вендорные; проверка типов не включается,
чтобы старая база не засыпала вас ошибками в первый же день.

## 📦 Установка

**macOS (Apple Silicon):** `VibeIDEA-0.4.1-aarch64.dmg` — перетащите приложение в «Программы».

Сборка **не подписана и не нотаризована**: при первом запуске macOS покажет «Файл не может быть
открыт». Нажмите **«Готово»**, затем Системные настройки → Конфиденциальность и безопасность →
пролистайте вниз, там появится **«Открыть всё равно»**. Либо снимите карантин командой:

```bash
xattr -dr com.apple.quarantine /Applications/VibeIDEA.app
```

Проверить, что скачался наш файл:

```bash
shasum -a 256 VibeIDEA-0.4.1-aarch64.dmg
# d0b57e860a5b436f7a6fe9ab1297ab68292951281f51fee5a415961999827706
```

**Что нужно на машине:** PHP 8.1+ и Node 18+. Для отладки PHP — Xdebug. Для базы — драйвер JDBC,
его скачает кнопка в панели «БД».

**Windows:** сборка делается на Windows-машине и выкладывается отдельно. Для неё этот выпуск и
важен: PHP там наконец работает.

**Обновление с 0.4.0:** ставится поверх, настройки сохраняются. Установленная 0.4.0 сама сообщит о
новой версии — канал обновлений в ней уже есть.

## 🚧 Чего пока нет

- **Правка данных в таблице БД** — только просмотр (намеренно: правка требует подтверждений и
  генерации `UPDATE` по ключу, а сделанная наполовину опаснее отсутствующей).
- **Автодополнение SQL по схеме**, cookies в HTTP-клиенте.
- **Подпись сборки** — нужны учётные записи разработчика Apple и сертификат для Windows.

## 🔬 Честно о зрелости

1389 тестов, четыре гейта исходников и проверка дистрибутива, которая **запускает** встроенные
серверы и адаптеры, а не проверяет наличие файлов. Именно она поймала, что в сборку едет вчерашний
набор зависимостей без лаунчера Phpactor.

Обкатывает по-прежнему один человек. **Панели HTTP и БД в живой работе не обкатаны**, живой прогон
точки останова в установленной IDE не делался. Если у вас не сработает, это самый полезный
[issue](https://github.com/VibeBrains/VibeIDEA/issues/new), который сейчас можно завести.
