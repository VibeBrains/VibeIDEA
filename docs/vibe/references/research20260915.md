## Находки по темам

### 1. Подписка Claude через claude-agent-acp

- **Пауза биллинга.** Anthropic собирался с 15.06.2026 перевести `claude -p`, Agent SDK и сторонние приложения со входом через подписку на отдельный кредит по ценам API (Pro $20, Max 5x $100, Max 20x $200) и отложил это в день запуска.
  Сейчас: *«nothing has changed: Claude Agent SDK, claude -p, and third-party app usage still draw from your subscription's usage limits»*.
  https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan
- **Zed** пишет, что при возврате плана расход через ACP в любом клиенте уйдёт в кредит, и оценивает подорожание в 15–30 раз. https://zed.dev/blog/anthropic-subscription-changes
  Что Anthropic предупредит заранее — только в пересказах СМИ, **слух**.
- **Правила брендинга Agent SDK** — проверено дословно: разрешено «Claude Agent», **не разрешено «Claude Code» и «Claude Code Agent»**.
  https://code.claude.com/docs/en/agent-sdk/overview
- **Адаптер 0.77.0** (14.09.2026): удалена настройка `claudeCode.options.agent`, у вызовов инструментов появились имена. Нас не задевает — `claudeCode.options` в коде нет.
  https://github.com/agentclientprotocol/claude-agent-acp/releases

**Проверено командой:** сид `agents.json` подписывает агента `"name": "Claude Code"`; решение №76 от 11.09 переименование отклонило из-за ключа сессии, довода о правилах брендинга не рассматривало.

→ VibeIDEA: переименование, миграция ключа и новое решение взамен №76 — **сид + фича**; факты паузы — **сид**.

### 3. acp.json и реестр ACP-агентов

### 7. Rewind и fork поверх методов сессий ACP

- В v1 стабилизированы: `session/list` 09.03, `session/resume` 22.04, `session/close` 23.04, `session/delete` 05.06.2026; fork — нет. https://agentclientprotocol.com/updates
- `resume` объявляется `sessionCapabilities.resume`, `session/load` — отдельной `loadSession`; возможности независимы (проверено по странице). https://agentclientprotocol.com/protocol/v1/session-setup
- RFD `session/fork` — черновик. https://agentclientprotocol.com/rfds/session-fork
- claude-agent-acp объявляет `close`, `delete`, `fork`, `list`, `resume`, `subagents`; fork у него `unstable_forkSession`. https://raw.githubusercontent.com/agentclientprotocol/claude-agent-acp/main/src/acp-agent.ts
- Cline: чекпоинты с Restore Files / Restore Task Only / Restore Files & Task. https://docs.cline.bot/core-workflows/checkpoints , https://github.com/cline/cline/releases

**Дефект, проверен командой:** `AcpClient.kt:394` — `resumeSession = agent?.get("loadSession")`. Агент с `sessionCapabilities.resume`, но без `loadSession`, никогда не продолжает сессию.

→ VibeIDEA: чинить чтение — **фича (малая)**, приоритет 1; `close`, `list`/`delete`, fork под возможностью, откат в трёх режимах — **фичи**.
