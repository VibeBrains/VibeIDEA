## Что проверено и брать не нужно

| Тема | Причина |
|---|---|
| 1. Переезд на открытый LSP-клиент платформы | Решение №73: остаёмся на LSP4IJ; патча платформы нет, переименование `LspServer`→`LspClient` нас не задевает (grep пуст); у платформы нет `willRenameFiles` |
| 2. MCP 2026-07-28 на нашем сервере | Уже сделано: `server/discover`, `resultType`, `ttlMs`/`cacheScope` у `tools/list`, заголовки `Mcp-Method`/`Mcp-Name` (`McpServer.kt`, №78). _Поправка 17.09: у `server/discover` подсказок кэша не было, хотя спека требует их и там — добавлены 17.09_ |
| 2. Полный MRTR в клиенте | YAGNI: клиент ходит к серверу памяти, `input_required` ему не нужен |
| 3. `iss`, `application_type`, CIMD | OAuth-клиента MCP у нас нет (№41, №47, №53); OAuth ведут сами ACP-агенты |
| 4. Отличия SSE MiniMax из pi#2768 | Слух: гипотезы без текста ошибки и без фикса; маршрут и ключи уже в сиде (№62) |
| 5. DeepSeek V4.1-Flash | Сид совпадает с ценами, окнами пика, `deepseek-flash` и Anthropic-адресом; роль по умолчанию — №24 |
| 6. Счётчик квоты GLM по формуле | Нечестен: пересчёт у Z.ai не документирован, расход вне IDE не виден, 3×/2× — слух про 5.1 |
| 7. Данные K3 в сиде | Совпадают с вендором: `kimi-k3`, 1 048 576, $3/$0.30/$15, без ступеней по длине |
| 7. Роль «анализ репозитория» сейчас | Не работает: шаг с `model` без инструментов и файлов |
| 8. Выбор поставки у агента с npx и binary | Уже так: `AgentRegistry.deliveryOf` проверяет npx/uvx раньше binary |
| 8. Реестр как источник `agents.json` | №81: каталог — выбор человека, версии в сиде протухнут |
| 9. Подписка Claude через Agent SDK | №65 и шапка `agents.json` на месте; пауза изменений действует, новой даты нет |
