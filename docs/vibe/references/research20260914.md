## Находки по темам

### 1. Claude через claude-agent-acp

- Пакет `@agentclientprotocol/claude-agent-acp`; старый `@zed-industries/claude-code-acp` в реестре npm помечен переименованным.
  https://github.com/agentclientprotocol/claude-agent-acp, https://registry.npmjs.org/@zed-industries/claude-code-acp
- Способы входа: `claude-ai-login` (подписка), `console-login` (API по токенам), `claude-login` (удалённые среды); ошибка `authRequired` при отсутствии или истечении учётных данных.
  https://raw.githubusercontent.com/agentclientprotocol/claude-agent-acp/main/src/acp-agent.ts
- Возможности: `loadSession`, `promptCapabilities {image, embeddedContext}`, `mcpCapabilities {http, sse}`, настройки сессии: быстрый режим, режим, уровень усилия.
- Выпуски 0.71–0.76 (31.08–09.09): подагенты, форк сессии, отказ от подписки при `--hide-claude-auth`, `authStatus`, рекомендуемые значения настроек.
  https://github.com/agentclientprotocol/claude-agent-acp/releases
- Лимиты подписки Pro/Max при OAuth прямо не подтверждены; метод `claude-ai-login` называется «Use Claude subscription».

→ VibeIDEA: уже реализовано; новое — настройки-списки, тема 2.

### 2. ACP v2 и настройки сессии

- Настройки сессии стабилизированы 04.02.2026, тумблеры — 06.07.2026; клиент включает тумблеры возможностью `session.configOptions.boolean`.
  https://agentclientprotocol.com/updates, https://agentclientprotocol.com/announcements/boolean-config-option-stabilized
- Значение настройки — поле **`currentValue`** у обоих типов; список несёт `options[{value, name}]`, категории `mode`/`model`/`model_config`/`thought_level`.
  https://agentclientprotocol.com/protocol/v1/session-config-options
- Черновик v2 от 20.07.2026: ход без жёстких «ходов», обязательные ID сообщений, структурные правки файлов; сроков нет.
  https://agentclientprotocol.com/announcements/acp-v2-draft

**Дефект, проверен командой:** `AcpClient.kt:418` читает `option["value"]`, спека — `currentValue`.
Любая настройка от агента, собранного по спеке, отбрасывается, тумблеры тоже.
Комментарий `AcpTypes.kt:79-80` («стабилизирован только тумблер») неверен: списки стабилизированы раньше.

→ VibeIDEA: чтение `currentValue` — **фича (малая)**, приоритет 1; тип `select` — **фича**, в пределах `vibe-agent`.
