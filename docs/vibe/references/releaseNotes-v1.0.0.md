## Что это

**VibeIDEA — открытая IDE PhpStorm-класса со встроенным агентом.**
Форк [intellij-community](https://github.com/JetBrains/intellij-community): платформа JetBrains, языки через LSP, вся агентская обвязка своя.

Это первый выпуск с номером 1.0.
Он не добавляет громкую возможность — он доводит до рабочего вида то, что вышло в 0.9.0: работу с внешними агентами по ACP, разбор правок и ленту чата.
Номер теперь обещание: настройки и файлы `.vibe` при обновлении сохраняются, а смену поведения мы будем объявлять заранее.

---

## Внешний агент работает как свой

**Агент, подключённый по ACP, теперь ведёт себя в IDE так же, как встроенный.**

- Правки, которые внешний агент делает своими инструментами, попадают в разбор по одной правке: принять и отклонить можно каждую отдельно, окно разрешения показывает diff.
- Решает, спрашивать ли вас, собственный режим агента.
  - Пилюля прав IDE при выбранном агенте ACP убрана: она ничего не решала и только путала.
  - Запросы разрешения всегда доходят до человека.
  - В недоверенном проекте закрыта и запись внешнего агента.
- Пилюли «Режим» и «Настройки» заполняются до первого сообщения: выбранный агент запускается сам, а сессия открывается без запроса к модели.
- В пилюле режима виден действующий режим агента; описания вынесены в подсказки.
- **Окно разрешения** соразмерно тексту: команда в моноширинном блоке, кнопки «Разрешить» и «Отклонить»; через него же идут остальные длинные подтверждения.
- **Вход посреди разговора**: если агент потерял авторизацию, лента предлагает «Войти» и подсказывает `claude /login`; терминальный вход открывается во вкладке Терминала.

## Чекпоинты

- Снимки перед ходом агента лежат в ссылке `refs/vibe/checkpoints`, и `git gc` их не уносит.
- Откат удаляет и файлы, которые агент создал после снимка.
- Старые снимки убираются сами; перед командами, которые их могут задеть, IDE предупреждает.
- Контракт общий с VibeIDE: снимок одной IDE читается другой.

---

## Чат

- **Разделитель между лентой и композером**: тянется мышью, пропорция запоминается; высота композера ограничена 40% панели.
- Текст ленты переносится заново при смене ширины окна.
- Слова агента и его вызовы идут в порядке прихода: слова между вызовами стали отдельными сообщениями и записями истории, вызовы и мысли стоят там, где случились.
- Карточка терминала в ленте сворачивается, когда команда закончилась; если вы развернули её сами, она не свернётся.
- Прямой чат продолжает с места: ход, в котором не было слов, больше не обрывается, потолок в 8 раундов заменён контрольными точками.
- Вызов с пустыми аргументами не принимается за повтор.

## Редактор и правки

- Кнопки «Принять» и «Отклонить» над правкой срабатывали вхолостую; теперь действие выполняется при отпускании кнопки.
- Двойной клик в файле с языковым сервером выделяет слово, а не всю шаблонную строку; четвёртый клик выделяет предложение.
- В окне сравнения двойной клик снова выделяет слово, а не блок.
- Сбои фоновых запросов языковых серверов идут в журнал, а не всплывашками.
- ESLint больше не падает на пустом пути к Node.

## Установка

**macOS (Apple Silicon):** `VibeIDEA-1.0.0-aarch64.dmg` — перетащить в «Программы».

```bash
shasum -a 256 VibeIDEA-1.0.0-aarch64.dmg
# a70862542a7434d9bd90491860c95ccd663f8506d8f3f2820eaebc1a5c05b055
```

**Windows (x64):** `VibeIDEA-1.0.0.exe` — обычный инсталлятор; или `VibeIDEA-1.0.0.win.zip` — распаковать куда угодно и запустить `bin\idea64.exe`.

```powershell
Get-FileHash VibeIDEA-1.0.0.exe -Algorithm SHA256
# 366c7cb54191757d50620d934527a231843ae022775866d8c7da5865791b2aa6
Get-FileHash VibeIDEA-1.0.0.win.zip -Algorithm SHA256
# e015e58af53ad12ce745d6a0996094eacc68ff47c14e4bad56e1e4ced5e9756b
```

**Linux (x64):** `VibeIDEA-1.0.0.tar.gz` — распаковать и запустить `bin/idea.sh`.

```bash
sha256sum VibeIDEA-1.0.0.tar.gz
# bf02b26f03de95c0c3f855b052a56aa78265f9c40c7bc47bbdec826746ef0e5d
```

**Что нужно на машине:** PHP 8.1+ и Node 18+.
Для отладки PHP — Xdebug.
Для базы — драйвер JDBC, его скачает кнопка в панели «БД».
Для общей памяти в чате — установленный VibeMemory.
Для голоса — модель распознавания: её предложит скачать кнопка микрофона.
Для голосовых сообщений через Telegram — ffmpeg.

**Обновление с 0.9.0:** ставится поверх, настройки сохраняются.

## Чего пока нет

Сборка **не нотаризована** у Apple: macOS предупредит при первом запуске, Windows покажет SmartScreen.

**Живыми ключами не проверено:** вход агента посреди разговора и разбор правок внешнего агента собраны по документации адаптеров и покрыты тестами, но с каждым адаптером руками не обкатаны.

**Про Windows честно:** `.exe` собран здесь же, на macOS, и проверен по составу.
Тихой установкой на Windows он **не проверялся**.

**Про Linux честно:** артефакт собран здесь же и проверен по составу.
**На Linux он не запускался**: линуксовый лаунчер и JBR на маке выполнить нечем.

Обкатывает продукт один человек.
Если что-то ведёт себя не так — самый полезный [issue](https://github.com/VibeBrains/VibeIDEA/issues/new), который сейчас можно завести.
