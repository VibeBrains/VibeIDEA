## 🧱 Что это

**VibeIDEA — открытая IDE PhpStorm-класса со встроенным агентом.**
Форк [intellij-community](https://github.com/JetBrains/intellij-community): платформа JetBrains, языки через LSP, вся агентская обвязка своя.

Вторая цифра поднялась, потому что в выпуске есть новые возможности, а не только исправления.
Главное: модель в прямом чате научилась пользоваться инструментами, переходы по Ext JS догнали PhpStorm, а пайплайны стали умнее с деньгами.

---

## 🧭 Ext JS: переходы, как в PhpStorm

**Ctrl+Click в `.js` теперь понимает Ext JS, а не только строку с именем класса.**
PhpStorm делает это закрытым плагином JavaScript, которого в открытой платформе нет, поэтому разбор и индексы свои.

- Имя класса в `extend`, `requires`, `Ext.create` ведёт в его `Ext.define`.
- Короткий `xtype: 'orderGrid'` находит класс с `alias: 'widget.orderGrid'`.
- `this.метод()` и `me.метод()` ищутся в самом классе, затем в `mixins`, затем вверх по `extend`.
- `callParent` ведёт в тот же метод родителя.
- `getStore`, `setStore`, `applyStore`, `updateStore` ведут в ключ `store` блока `config`.
- Имя события в `fireEvent` или ключ `listeners` показывает все места, где событие вызывают и слушают.

Исходники фреймворка в проекте тоже индексируются, а минифицированный код — нет, чтобы короткие имена не превращались в тысячи мусорных целей.
Вывода типов нет: класс переменной не угадывается, поэтому `store.load()` предлагается списком одноимённых методов, если их немного.

После обновления первое открытие проекта займёт время на переиндексацию.

## 🔧 Модель в прямом чате пользуется инструментами

**Раньше модель провайдера в композере могла только отвечать текстом.**
Теперь она сама ищет по проекту и читает общую память — на всех трёх протоколах: OpenAI-совместимом, Anthropic и Gemini.

- **Инструменты IDE:** кто импортирует файл, как связаны два файла, где встречается имя, что проект уже записал по теме, какие решения приняты.
- **Общая память VibeMemory:** поиск и чтение записей и истории сессий, если VibeMemory установлен.
- **Запись спрашивает вас.** Сохранить решение или изменить память модель может только после вашего «да» на этот конкретный вызов, с аргументами в диалоге. В недоверенном проекте запись закрыта целиком.
- **Модель помнит, что нашла.** Обмен с инструментами хранится в истории треда, и на уточняющий вопрос она отвечает по найденному, а не по своему пересказу.
- **Много инструментов — поиск по ним.** Когда их больше двадцати, модель получает не все схемы, а поиск и подгружает нужные.

Каждый вызов назван в ленте и в журнале аудита — без аргументов и результата.
Выключается одной галкой: Settings → Tools → VibeIDEA → Агент.

## 🗜 Длинный разговор не переполняет окно

**Прямой чат научился сворачивать историю.**
Когда оценка переходит порог окна модели, сначала убираются результаты старых вызовов инструментов, и только если этого мало — ранние сообщения сворачиваются в сводку той же модели.
Последние сообщения и закреплённые не трогаются.

В оценку входят схемы инструментов: они уходят в каждом запросе, и без них порог срабатывал поздно именно в сессиях с инструментами.
Порог, цель и число нетронутых сообщений — в настройках.

## ⛓ Пайплайны: модели, деньги и продолжение

- **Шаг ждёт дешёвого часа.** Шаг на своей модели с `"offPeak": true` запускается только вне пика цен этой модели. Пока модель в пике, прогон ждёт с уведомлением и кнопками «Запустить сейчас» и «Отменить прогон». Поле общее с VibeIDE.
- **Модель на роль.** В пайплайне можно задать модель по умолчанию для роли, а у шага — свою одной строкой `провайдер/модель`.
- **Потолки расходов агента** — в день, за прогон, в токенах; прогон останавливается на потолке.
- **Динамический пайплайн.** Оркестратор составляет шаги, а вы видите план до запуска и соглашаетесь или нет.
- **Прерванный прогон продолжается** с незавершённого шага, а не с начала.
- **`qa` пишет только тесты.** Код под тестом закрыт на запись; список тестовых путей — в общем с VibeIDE `.vibe/roles.json`.
- **Роль `critic`** — судит, ничего не пишет.

## 🔌 Внешние агенты

- **Настройки агента видны.** Модель, режим и уровень усилия, которые Claude через `claude-agent-acp` отдаёт списком, выбираются в пикере «Настройки ▾».
  Заодно исправлено: значения настроек читались не из того поля, и настройки агентов, собранных по спеке, пропадали целиком — тумблеры тоже.
- **Общая память у ACP-агентов.** Агент, которого запускает IDE, получает сервер памяти VibeMemory, если тот установлен.

---

## 🛡 Безопасность и журнал

- **Живой журнал и случаи эвалов закрыты от агента** — агент не может подправить собственный след или подогнать проверку под себя.
- **Трифекта на всю сессию.** Три признака утечки ловятся, даже когда растянуты на несколько ходов.
- **Форма запроса данных от агента проверяет ввод по схеме** до того, как он уйдёт агенту.
- **«Что прочитано»** на панели «Аудит» сводит, какие файлы и записи прочитал каждый агент, и отзывает одобрения в один шаг.
- **MCP-сервер IDE** в недоверенном проекте только читает; запись и запуск открываются отдельными переключателями.

## 📦 Как поставить

**macOS (Apple Silicon):** `VibeIDEA-0.6.0-aarch64.dmg` — перетащить в «Программы».

Сборка **не подписана**, поэтому при первом запуске macOS скажет, что не может проверить разработчика.
Обход: правый клик по `VibeIDEA.app` → **«Открыть»**, в диалоге пролистать вниз, там появится **«Открыть всё равно»**.
Либо снять карантин командой:

```bash
xattr -dr com.apple.quarantine /Applications/VibeIDEA.app
```

Проверить, что скачался наш файл:

```bash
shasum -a 256 VibeIDEA-0.6.0-aarch64.dmg
# 9ad22635da88f0a1f26babed5499e44a6b8aab4bf25ff7acd09bff592de5245f
```

**Windows (x64):** `VibeIDEA-0.6.0.exe` — обычный инсталлятор; или `VibeIDEA-0.6.0.win.zip` — распаковать куда угодно и запустить `bin\idea64.exe`.

Сборка **не подписана**: SmartScreen покажет «Система Windows защитила ваш компьютер» — **«Подробнее»** → **«Выполнить в любом случае»**.
Касперский может удалить `idea64.exe` по поведению (`PDM:Trojan.Win32.Generic`): это детект неподписанного новичка, а не находка в файле.

Проверить, что скачался наш файл (PowerShell):

```powershell
Get-FileHash VibeIDEA-0.6.0.exe -Algorithm SHA256
# 4a999b9dd5f2b744b66ccd451ce81ec3c76feec63936a96db4c95fde31fec8d8
Get-FileHash VibeIDEA-0.6.0.win.zip -Algorithm SHA256
# 4034e6e189e5444e8d84f3ef603efb0a3e6ce0487b5f635ee7d736d9cfd47a85
```

**Linux (x64):** `VibeIDEA-0.6.0.tar.gz` — распаковать и запустить `bin/idea.sh`.

```bash
sha256sum VibeIDEA-0.6.0.tar.gz
# c19fcfa0e150617403527cc144eff7bdb79871a36468a536798c0b489ec3509f
```

**Что нужно на машине:** PHP 8.1+ и Node 18+.
Для отладки PHP — Xdebug.
Для базы — драйвер JDBC, его скачает кнопка в панели «БД».
Для общей памяти в чате — установленный VibeMemory.

**Обновление с 0.5.0:** ставится поверх, настройки сохраняются.

## ⚠️ Чего пока нет

Сборка **не подписана** ни на одной из систем: macOS предупредит при первом запуске, Windows покажет SmartScreen.

**Про Linux честно:** артефакт собран здесь же, на macOS, и проверен по составу — плагины на месте, индекс в порядке.
**На Linux он не запускался**: линуксовый лаунчер и JBR на маке выполнить нечем.

Обкатывает продукт один человек, и **этот выпуск в руках не проверялся**: собран и проверен тестами и гейтами, но не живой работой.
В первую очередь не обкатаны: инструменты и поиск инструментов в прямом чате, свёртка истории, переходы по Ext JS на большом проекте, настройки-списки у Claude через ACP, ожидание дешёвого часа в пайплайне.
Если что-то из этого ведёт себя не так — самый полезный [issue](https://github.com/VibeBrains/VibeIDEA/issues/new), который сейчас можно завести.
