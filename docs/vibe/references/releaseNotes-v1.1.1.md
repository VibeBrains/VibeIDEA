## Что это

**VibeIDEA — открытая IDE PhpStorm-класса со встроенным агентом.**
Форк [intellij-community](https://github.com/JetBrains/intellij-community): платформа JetBrains, языки через LSP, вся агентская обвязка своя.

Этот выпуск убирает у агента лишние вопросы и зависшие карточки, добавляет подсветку шаблонов FreeMarker и поля карточки у провайдеров вроде Vertex и Azure.
Ещё в нём YAML-кавычки в шапках правил, виджет задач в каждом проекте и строка диагностики о чужих файлах инструкций.
Ставится поверх 1.1.0.

---

## Шаблоны FreeMarker

**`.ftl`, `.ftlh` и `.ftlx` открываются как файлы своего языка — с цветом и своим значком.**

- Открытая платформа FreeMarker не знает: шаблон открывался «неизвестным типом», без единого цвета.
- Грамматика своя: чужая открытая не видит `${…}` внутри значения атрибута, а шаблоны HL7 CDA состоят ровно из таких строк.
- Подсвечены директивы `<#if>`/`<#list>`/`<#macro>`, вызов `<@x>`, интерполяция `${…}` в тексте и в атрибуте, встроенные `?has_content` и комментарий `<#-- -->`.
- Разметка вокруг остаётся родной: HTML для `.ftl` и `.ftlh`, XML для `.ftlx`.
- Квадратная нотация `[#if]` не подсвечивается; автодополнения и разбора нет — только цвет и тип файла.

## Агент спрашивает только о необратимом

**На автопилоте `rm` внутри проекта или временной папки больше не задаёт вопрос.**

- Границу задаёт область, а не слово: все цели одной команды `rm` лежат в проекте или `TMPDIR`/`/tmp`, без масок, `..`, `~`, `.git` и подстановок.
- Остальное остаётся вопросом: домашняя папка, корень, хранилище репозитория, обёртки вроде `sudo` и `sh -c`, вторая команда в строке.
- Символьные ссылки временных каталогов на macOS (`/tmp` → `/private/tmp`) проверку больше не сбивают.
- В режимах «Правки», «Вручную» и «План» поведение не менялось.

## Карточки и журнал закрываются вместе с ходом

**Вызов инструмента, которому агент не сообщил конец, закрывается вместе с ходом.**

- Раньше прерванный ход или умершая сессия оставляли вызов «в работе»: карточка крутилась, терминал жил, а в аудите записи не было.
- Теперь конец хода закрывает такие вызовы, гасит их терминалы и пишет запись; успехом аудит считает только завершённый вызов.
- Откат папки по чекпоинту сбрасывает журнал разбора правок.
  После `/undo` записи описывали состояние, которого больше нет: «Отклонить» на них вернуло бы уже откаченное.

## Чужие инструкции и MCP-серверы

**Диагностика называет `AGENTS.md` и `CLAUDE.md`, которых проект не добавлял.**

- Строка «Файлы инструкций» показывает файл выше корня проекта или файл не под контролем git.
- Такие указания приезжают с распакованным архивом, папкой синхронизации или случайной загрузкой, а агент читает их как правило.
- Если git не ответил, файл неотслеживаемым не называется: ложное предупреждение учит пролистывать строку.
- Обход не заходит в деревья зависимостей, поэтому `node_modules` не даёт сотен мнимых инструкций.

**Проектный `.vibe/mcp.json` не запускает команды в недоверенной папке.**

- Открыть клон ещё не значит разрешить его команды: проектный слой читается только при доверии к проекту.
- Общий `~/.vibe/mcp.json` работает и в недоверенной папке, а страница «MCP-серверы» по-прежнему показывает оба файла.

## Провайдеры: поля карточки и токен Google

**Провайдер может объявить поля, которые человек заполняет в его карточке.**

- Так описываются Vertex, Azure OpenAI и Bedrock, у которых адрес и заголовки собираются из данных аккаунта.
- Значение подставляется в `baseURL`, строковый `models.fetch`, `headers` и `query` вместо объявленного `default`.
- Обязательное поле без значения оставляет провайдера в каталоге, но запросов он не шлёт и говорит, каких полей не хватает.
- Необязательное поле даёт пустую подстановку, а заголовок или query-параметр, державшийся только на нём, выпадает целиком.
- Значение поля `as: "headers"` разбирается как JSON-объект и вливается в заголовки.
- Введённые значения живут в настройках IDE; файл набора их не хранит.

**У провайдера появился источник ключа `google-adc` — токен Google OAuth из Application Default Credentials.**

- Ключ не ищется ни в хранилище, ни в `.env`: токен берётся из файла, который кладёт `gcloud auth application-default login` или сервисный аккаунт.
- В запрос уходит `Authorization: Bearer`, обновляемый к каждому запросу.
- Испорченный файл учётных данных останавливает провайдера с названной причиной — пустой заголовок не уходит.
- В карточке такого провайдера нет поля ключа — вместо него кнопка «Проверить».

**Карточка провайдера умеет показывать ссылки на его документацию и на страницу, где получить ключ.**

- Адреса берутся из полей `docsUrl` и `apiKeyUrl` файла провайдера.
- Открываются только `http` и `https`.

## Правила и навыки

**Шапка правила и навыка понимает YAML-кавычки и блоки `>` и `|`.**

- Раньше значение в двойных кавычках показывалось вместе с кавычками, а блок `>` — знаком `>` вместо описания.
- Теперь экранирование раскрывается, а описание в списке навыков и в попапе `/skill:` читается человеком и моделью одинаково.
- Одно и то же описание читают правила проекта, пакет навыка и список навыков; раньше каждое место разбирало шапку по-своему.

## Тулбар и набор

**Виджет задачи в тулбаре виден в каждом проекте.**

- Платформа показывает его только при нетривиальной задаче или частном сервере трекера, поэтому в чистом проекте место пустовало.
- Первый запуск сборки включает настройку «Always display the task combo» один раз на профиль; выключенная руками остаётся выключенной.

**Набор VibeBrains в сборке обновлён.**

- В наборе правило бригадира теперь называется `brigadier`, в каталоге провайдеров шесть новых записей.

**macOS (Apple Silicon):** `VibeIDEA-1.1.1-aarch64.dmg` — перетащить в «Программы».

```bash
shasum -a 256 VibeIDEA-1.1.1-aarch64.dmg
# 2beb048a10742c6f1a0d120a0b02aa8e71d6a6af19adbb8b9478e4ab2a69e238
```

**Windows (x64):** `VibeIDEA-1.1.1.exe` — обычный инсталлятор; или `VibeIDEA-1.1.1.win.zip` — распаковать куда угодно и запустить `bin\idea64.exe`.

```powershell
Get-FileHash VibeIDEA-1.1.1.exe -Algorithm SHA256
# 45bbcf3f826946d74c668bc466b9c9519be9c9fdff3a54d2a3e4bf0c6d50570c

```

**Linux (x64):** `VibeIDEA-1.1.1.tar.gz` — распаковать и запустить `bin/idea.sh`.

```bash
sha256sum VibeIDEA-1.1.1.tar.gz
# 9e8e49f72c7c0cba4c8af5d9cc6f0fc4c4de31d513789c9b090ff5bd287e8415
```

**Что нужно на машине:** PHP 8.1+ и Node 18+.
Для отладки PHP — Xdebug.
Для базы — драйвер JDBC, его скачает кнопка в панели «БД».
Для общей памяти в чате — установленный VibeMemory.
Для голоса — модель распознавания: её предложит скачать кнопка микрофона.
Для голосовых сообщений через Telegram — ffmpeg.
Чтобы агент разбирал видео и аудио — ffmpeg.

**Обновление с 1.1.0:** ставится поверх.

## Чего пока нет

Сборка **не нотаризована** у Apple: macOS предупредит при первом запуске, Windows покажет SmartScreen.

**Живьём не проверено** (собрано, покрыто тестами, но руками не обкатано):

- подсветка FreeMarker: тип файла и цвет проверены лексером в тесте, но не в запущенной IDE; квадратная нотация `[#if]` не покрыта;
- виджет задачи в тулбаре: включение настройки проверено тестом, вид в живой IDE — нет;
- описания навыков `party` (блок `>`) и `na-paltsah` (двойные кавычки) в живом наборе не смотрели;
- поля карточки провайдеров и токен `google-adc`: проверены юнит-тестами без сети, живого аккаунта Google и живой IDE не было;
- диалог слияния файлов `.vibe` без плагина VCS — пункт, оставшийся с 1.1.0: в живой IDE без плагина VCS его не перепроверяли.

**Про Windows честно:** `.exe` собран здесь же, на macOS, и проверен по составу.
Тихой установкой на Windows он **не проверялся**.

**Про Linux честно:** артефакт собран здесь же и проверен по составу.
**На Linux он не запускался**: линуксовый лаунчер и JBR на маке выполнить нечем.

Обкатывает продукт один человек.
Если что-то ведёт себя не так — самый полезный [issue](https://github.com/VibeBrains/VibeIDEA/issues/new), который сейчас можно завести.
