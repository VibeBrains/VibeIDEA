## 🧱 Что это

**VibeIDEA — открытая IDE PhpStorm-класса со встроенным агентом.**
Форк [intellij-community](https://github.com/JetBrains/intellij-community): платформа JetBrains, языки через LSP, вся агентская обвязка своя.

Вторая цифра поднялась, потому что в выпуске есть новые возможности, а не только исправления.
В этом выпуске агент отвечает коротко и по делу, IDE ловит штампы в тексте, а прямой чат с моделью научился говорить с новыми моделями на их языке — GPT-6 через Responses API, Claude с рассуждением между ходами, OpenRouter со своим диалектом.

---

## ✂️ Сжатые ответы и быстрые настройки

**Модель отвечает без воды: без вежливостей, оговорок и пересказа своих шагов.**
Код, имена, команды и тексты ошибок остаются дословно.

- Включено по умолчанию; уровни «лёгкие», «полные» и «ультра», выключатель на виду.
- Код, коммиты и документы модель пишет обычным языком, предупреждения — полными фразами.
- Локальная модель получает короткую форму правил: у неё мало места под промпт.
- Кнопка быстрых настроек в ряду композера: сжатые ответы, глубина рассуждений, офлайн-режим, минимализм.

## 🧹 Детектор нейрослопа

**IDE находит в тексте штампы, которые выдают сгенерированную прозу.**
64 правила, без модели и без ключа.

- Действие «Нейрослоп в тексте» в меню редактора.
- Проверка ответа агента в конце хода: подсказать или вернуть на доработку.
- Правила проекта — файлом `.vibe/slop.json`, спека в справке.
- Дизайн-детектор читает тексты страницы тем же каталогом.

## 🔌 Модели и провайдеры

- **GPT-6 через Responses API**: инструменты и рассуждение вместе, как требует вендор.
- **Claude помнит рассуждение между ходами**, пока история не менялась, — и кэш промпта перестал промахиваться на прошлом ходе.
- **«Выключено» честное**: модель, которая думает по умолчанию, получает самый низкий уровень, а не молча думает на полную.
- **Отказ модели ведёт к запасной**: если первая отказалась отвечать, ход уходит на следующую модель цепочки.
- **Часовой кэш считается по своей цене**: раньше запись на час шла по цене пятиминутной.
- **OpenRouter со своим диалектом** рассуждения, `"auth": "none"` для серверов без ключа, `runsLocally` для моделей на своей машине.
- **Прокси по целям**: список «напрямую, мимо прокси» для провайдеров и агентов.
- **Диагностика** называет поля `extraBody`, которые вендор отвергнет, ещё до запроса.

## 🤖 Агент и инструменты

- **Память команды VibeMemory по HTTPS** — общая память для прямого чата и ACP-агентов, токен хранится только у VibeMemory.
- **Волны в пайплайнах**: шаги с одной меткой идут одновременно.
- **MCP-сервер может попросить ввод посреди вызова** — форма приходит тем же диалогом, что у агента.
- **Имя инструмента** видно рядом с заголовком вызова и в вопросе о разрешении.
- **Подмена описаний инструментов** после одобрения больше не проходит молча.
- **Точный переход по коду включён по умолчанию**; подсказка с Cmd показывает сигнатуру.
- **Смена ветки обновляет языковые серверы**, у каждого — «Проверить» и «Установить последнее».

## 🩹 Исправлено

- Иконка приложения в списке Finder и на Windows в мелких размерах — вместо пятна снова логотип.
- Картинка из буфера вставляется в композер.
- На Windows ключи провайдеров больше не считаются отсутствующими, когда хранилище не ответило.
- Схема `providers.json` не подсвечивает ошибкой файл, который верен по спеке.
- Шаблон из `slop.json` больше не может повесить IDE: у каждого правила свой срок.

## 💾 Установка

**macOS** — `.dmg` (Apple Silicon) или `.sit`.
**Windows** — инсталлятор `.exe` или архив `.win.zip`.
**Linux** — `.tar.gz`.

**Что нужно на машине:** PHP 8.1+ и Node 18+.
Для отладки PHP — Xdebug.
Для базы — драйвер JDBC, его скачает кнопка в панели «БД».
Для общей памяти в чате — установленный VibeMemory.

**Обновление с 0.7.0:** ставится поверх, настройки сохраняются.

## ⚠️ Чего пока нет

Сборка **не нотаризована** у Apple: macOS предупредит при первом запуске, Windows покажет SmartScreen.

**Живыми ключами не проверено:** новые провода и причуды моделей собраны по документации вендоров и покрыты тестами, но ответа настоящего вендора не видели.

**Про Windows честно:** `.exe` собран здесь же, на macOS, и проверен по составу.
Тихой установкой на Windows он **не проверялся** — сравнение инсталлятора с архивом сборка вне Windows пропускает сама.

**Про Linux честно:** артефакт собран здесь же и проверен по составу — плагины на месте, индекс в порядке.
**На Linux он не запускался**: линуксовый лаунчер и JBR на маке выполнить нечем.

Обкатывает продукт один человек.
Если что-то ведёт себя не так — самый полезный [issue](https://github.com/VibeBrains/VibeIDEA/issues/new), который сейчас можно завести.
