## Что проверено и брать не нужно

| Тема | Причина |
|---|---|
| 1. Список агентов по умолчанию из реестра | Zed так не делает: `agent_servers` по умолчанию пуст, установка кнопкой; №81 подтверждается |
| 1. Канал `registry-for-jetbrains-preview.json` | Агенты в нём не проверяются запуском, сделан под JetBrains |
| 2. «Подвох» VentureBeat — кредит Agent SDK | Статья 13.05.2026, перекрыта паузой 15.06; официальная статья 15036540 не менялась, новой даты нет |
| 2. Свой провайдер Anthropic на подписочном OAuth-токене | Запрещено (страница Legal, по пересказу The Register — первоисточник не открылся) и отключено API с 09.01.2026 |
| 3. Сессии, `MCP-Protocol-Version`, `Mcp-Method`/`Mcp-Name`, `_meta`, `resultType` | Уже так в `McpServer.kt`; `McpStdioClient` читает `resultType` с 17.09 |
| 3. Статья Google о масштабировании без сессий | Про балансировщики и Cloud Run; наш сервер — один процесс на loopback |
| 3. Проба `server/discover` в `McpStdioClient` | YAGNI: VibeMemory на `2025-06-18` с `initialize` (`protocol.rs:14`) |
| 4. DPoP (SEP-1932), Workload Identity Federation (SEP-1933) | Черновики; оба — профили OAuth, OAuth-клиента MCP у нас нет (№41, №53) |
| 4. Прогрессивное обнаружение инструментов | Серверная часть — план без SEP; клиентский гайд разрешает свой поиск (`ToolSearch.kt`); порог в процентах окна — когда инструментов станет больше 20 |
| 5. K2.8 на `api.moonshot.ai/anthropic` с ключом Kimi Code | Посылка неверна: K2.8 Preview есть только в Kimi Code, хост `api.kimi.com/coding`, id `kimi-for-coding` |
| 5. Причуда `NO_SAMPLING` для Kimi | Temperature уходит только заданная человеком; хватит строки в сиде |
| 6. GLM-5.3 на Anthropic-маршруте в Coding Plan | Страница вендора сегодня та же: подписчикам только OpenAI-маршрут |
| 6. Предупреждение о пике в doctor | Нечестно: тариф (кредиты или Legacy V2) IDE не знает; №97 отвергло догадку в виде числа |
| 7. Синк на IntelliJ IDEA 2026.2.3 | Линия 262, мы на 263 (№57); починка IJPL-251259 уже в нашей базе и `JBScrollBar` не трогает |
| 8. Текстовое правило «подтверждать сеть и разрушительное» | Инцидент AEPD 14.09 — агент злоумышленника против чужого сайта; у нас сеть и разрушительное уже спрашиваются кодом (`ShellSafetyAnalyzer`, `Trifecta`), а `rules/security.mdc` уже говорит, что правило не граница |
