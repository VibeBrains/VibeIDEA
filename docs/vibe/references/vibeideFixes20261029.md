# Починки VibeIDE 15–29.10.2026: сверка с VibeIDEA

Список из 34 починок соседнего продукта сверен по коду `vibe-plugins/`. По каждому пункту: есть ли у нас тот же
дефект или дыра, и что сделано. Дефект малой или средней правки — исправлен с тестом; крупный — вынесен в
[roadmap](../roadmap.md); отсутствующий — назван с причиной.

**О хешах.** Хеши коммитов VibeIDE из брифа не перенеслись в эту сессию: контекст был сокращён до сути пунктов.
