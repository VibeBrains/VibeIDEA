# nick-vels/skills («Autopilot»): разбор и что взять (17.09.2026)

Разбор по просьбе владельца. Репозиторий читался через GitHub API в raw-режиме, без клонирования и
без запуска кода. Всё, что сказано ниже о VibeIDEA, проверено по её коду и спекам.

## Что это

Один навык `skills/autopilot` — оркестратор цикла «слова заказчика → собранный проект» в одном
диалоге, для Claude Code, Cursor и Codex. MIT, 375 звёзд, последний пуш 19.08.2026.
`SKILL.md` держит только режимы, порядок фаз и гейты; механика каждой фазы лежит в `phases/` и
читается в момент входа в фазу.

Фазы: подготовка (каталог прогона, дашборд) → манифест требований → опрос → спека → план тасков по
ярусам и волнам → исполнение субагентами → ремонт → ревью по трём осям → слепая приёмка → память
проекта. Сквозные гейты G1–G4; отдельный файл-каталог самооправданий, который читают в трёх точках.

Несущая идея — **манифест**: бриф пользователя записан дословно и не редактируется, дополнения
дописываются датированными строками, а требования пронумерованы с цитатой и статусом. Снять
требование может только пользователь и только цитатой.

## Что взять

| Что | Подсистема | Трудоёмкость | Польза |
|---|---|---|---|
| Дословный бриф и требования с цитатами; приёмка сверяется с ним, а не со спекой | сиды пайплайнов + шаг | сид + фича (малая) | сегодня якорь приёмки — спека, то есть пересказ агента |
| Потолок шага просит передачу вместо обрыва | pipelines | фича (средняя) | сейчас `StepLimits` обрывает шаг посреди правки через `cancel()` |
| Структурированный возврат шага (`STATUS/FILES/TESTS/…`) | pipelines + сид | фича (малая) + сид | следующий шаг получает хвост ответа ≤2000 символов, то есть прозу |
| `interfaces.md` — накопительный контракт швов между шагами | сиды | сид | в нашем `feature` ревьюер намеренно не видит артефактов, и переизобретение не видит никто |
| Редакция секрета во вводе пользователя, а не только в @-контексте | security | фича (малая) | ключ, вставленный в поле ввода, уезжает модели как есть |
| Каталог самооправданий, читаемый в трёх точках | сиды | сид | `grill` ломает план, а это ловит отговорку посреди прогона |
| Волны и зоны: параллельные шаги по непересекающимся путям | pipelines | фича (крупная) | зоны уже принудительны (`RolePaths.mayWrite`), но для планирования не используются |

Проверено в нашем коде:
`acceptance` шага машинно не проверяется — единственное употребление `AgentPanel.kt:4519`, дописывание в промпт.
Потолок шага: `StepLimits.check` → `stepLimitHit` → `client.cancel()` (`AgentPanel.kt:4063–4083`).
Передача между шагами — пути файлов и хвост ответа ≤2000 символов (`pipelinesSpec.md`, «Передача между шагами»).
Маскирование секретов — только у @-контекста и по настройке (`ContextSerializer.load`, `AgentPanel.kt:2374`).

## Что не берём и почему

| Что | Причина |
|---|---|
| `tools/sync.py` и их дашборд | Поднимает `python3 -m http.server` на каталоге прогона без аутентификации, переживает сессию и убивает соседние процессы сканом `ps`; у нас есть тулвиндоу прогонов, задач и журнала |
| Каталог `.autopilot/` в репозитории пользователя | Наши артефакты живут в `.vibe/local/` — осознанное решение |
| Четыре режима × три глубины | У нас уже есть `AutopilotPolicy`; вторая шкала автономности разойдётся с первой |
| Числа как контракт (50 вызовов, ярусы T0–T3, «не больше 16 тасков») | Их собственный аудит называет это калибровкой без замера |
| `tools/measure-run.py` | Читает недокументированную схему `.jsonl` Claude Code; у нас `SpendLedger`, `ContextTax`, `/trace` |
| `skills-lock.json` и установка через `npx skills` | У нас одобрение навыка — sha256 всего каталога (`SkillApproval`), это строже |
| «Ревьюер живёт дольше таска» | У нас судящие роли по умолчанию `FRESH`; замена — файл швов, а не общая память ревьюера |

## Чему верить в их числах

- `docs/audit-2026-08-17.md` — не замер, а чтение файлов: токены посчитаны арифметикой по размерам,
  прогонов не было. Документ сам ставит себе «доказательность 4/10».
- README цифр успеха не называет вовсе, но и на аудит не ссылается; раздел про состав репозитория устарел.
- Отдельные наблюдения («тринадцать ремонтов на девять тасков», «паузы 444 и 7814 минут») — из одного
  прогона, данных под ними нет.
- Мы ничего из их кода не запускали: `sync.py` и `measure-run.py` оценены чтением.
