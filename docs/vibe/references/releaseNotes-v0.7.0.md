## 🧱 Что это

**VibeIDEA — открытая IDE PhpStorm-класса со встроенным агентом.**
Форк [intellij-community](https://github.com/JetBrains/intellij-community): платформа JetBrains, языки через LSP, вся агентская обвязка своя.

Вторая цифра поднялась, потому что в выпуске есть новые возможности, а не только исправления.
Главное: у IDE появился свой набор из восьми тем — включая первую светлую, — фронтенд закрыт целиком (Vue, Svelte, Astro, стили в шаблонных строках), а переходы по коду перестали обещать то, чего сервер не знает.

---

## 🎨 Восемь своих тем, и одна из них дневная

**Раньше тема красила только панель агента, а остальная IDE оставалась чужой.**
Теперь тема красит всё: деревья, тулбар, всплывающие окна, диалоги и центральную панель с кодом.

- Восемь тем: Neon Dark, Midnight, Graphite, Terracotta, Espresso, Honey, Tobacco и светлая **Porcelain**.
- **Porcelain — первая светлая**, и палитра ей подобрана заново, а не вывернута из тёмной: на свету акцент обязан быть темнее фона.
- Пара «день/ночь» из коробки наша: Porcelain днём, Neon Dark ночью.
- Страница Settings → Tools → VibeIDEA → Оформление: список с пометкой «наша», кружками палитры и образцом кода.
- Схема редактора идёт за темой: сменили тему — сменился и цвет кода, а не всё вокруг него.

Отдельно про читаемость: контраст теперь **измеряется**, а не подбирается на глаз.
Тусклый текст ленты и композера в шести темах из восьми шёл ниже порога — худший случай 2.08 при планке 4.0, и это были не украшения, а подписи, которые надо читать.
Цвета текста разведены с цветами украшений и подняты до 4.3+; гейт мерит одиннадцать пар «текст на фоне» и схемы редактора.

## 🧩 Фронтенд закрыт целиком

- **Vue, Svelte и Astro** — своими языковыми серверами, а не подсветкой «на глазок».
- **Стили в шаблонных строках** — подсказки и ошибки CSS прямо внутри `styled.div` и `css`.
- **Подсветка пяти языков**, которых платформа не знает: `.vue`, `.svelte`, `.astro`, `.sass`, `.styl`.
- Раньше в этой же линии приехали Angular, Tailwind, Some Sass, Stylus и диалекты PostCSS.

Всё едет в комплекте: серверы лежат внутри сборки, из интернета при первом запуске ничего не тянется.

## 🧭 Точная навигация

**Ctrl+Click подчёркивает только то, что языковой сервер действительно умеет открыть.**
Раньше подчёркивалось всё подряд, и половина переходов заканчивалась ничем.

Ответы сервера кэшируются по позиции, поэтому подсветка не дёргает сервер на каждое движение мыши.
Включается ключом реестра; по умолчанию выключено, пока не обкатано на больших проектах.

## 🤖 Агент

- **Процессы видны человеку**: что агент запустил, что ещё работает, чем кончилось.
- **Правки принимаются и отклоняются по одной**, а не всем ходом сразу.
- **Предохранитель необратимых команд** — опасное действие останавливается и спрашивает.
- **Трассировка происхождения значения** и починка ошибок одним действием.
- **Свои MCP-серверы**, поиск по документации продукта, режимы прав, экспорт разговора, счётчик контекста.
- **Прокси больше не захватывает локальные модели**: Ollama на `localhost` и локальный muse-glimmer идут мимо прокси всегда.
- **Версия протокола ACP сверяется**: расхождение называется строкой, а не превращается в странности.
- **`AGENTS.md` читается как источник правил** — и корневой, и пакетные, ближний к файлу сильнее.

## 💾 Установка

**macOS** — `.dmg` (Apple Silicon) или `.sit`.
**Windows** — инсталлятор `.exe` или архив `.win.zip`.
**Linux** — `.tar.gz`.

**Что нужно на машине:** PHP 8.1+ и Node 18+.
Для отладки PHP — Xdebug.
Для базы — драйвер JDBC, его скачает кнопка в панели «БД».
Для общей памяти в чате — установленный VibeMemory.

**Обновление с 0.6.0:** ставится поверх, настройки сохраняются.

## ⚠️ Чего пока нет

Сборка **не нотаризована** у Apple: macOS предупредит при первом запуске, Windows покажет SmartScreen.

**Что проверено запуском:** macOS-образ поднят и проверен на темах — интерфейс и код меняются вместе, ошибок таблицы умолчаний в логе нет.

**Про Windows честно:** `.exe` собран здесь же, на macOS, и проверен по составу.
Тихой установкой на Windows он **не проверялся** — сравнение инсталлятора с архивом сборка вне Windows пропускает сама.

**Про Linux честно:** артефакт собран здесь же и проверен по составу — плагины на месте, индекс в порядке.
**На Linux он не запускался**: линуксовый лаунчер и JBR на маке выполнить нечем.

Обкатывает продукт один человек.
В первую очередь не обкатаны: точная навигация на большом проекте, Vue и Astro на живом коде, светлая тема в долгой работе.
Если что-то ведёт себя не так — самый полезный [issue](https://github.com/VibeBrains/VibeIDEA/issues/new), который сейчас можно завести.
