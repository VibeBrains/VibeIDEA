## Сделано сейчас

### B2. Дедупликация инструментов по имени

`providers/ToolCalls.distinct` оставляет первое определение каждого имени; применяется в `openAiTools`, `anthropicTools`,
`geminiTools` и `ResponsesWire.tools`, поэтому дубль не уходит ни на один провод. Имя — это идентичность, по которой модель
вызывает инструмент; второе определение с тем же именем провайдер отвергает целиком (`duplicate tool declaration`, Kimi Code 2.5.2).
Тест — `ToolCallsTest.a duplicate tool name goes out once on every wire`: первый экземпляр сохраняется, описание второго не уезжает.

### C3. `speed: "fast"` у Opus 4.8 назван заранее

Клиент это поле не отправляет, поэтому единственный путь — рукописный `extraBody`. `ExtraBodyConflicts.Reason.FAST_MODE` называет его
для `^claude-opus-4-8` на Anthropic-проводе; у Opus 5.5 fast mode остаётся, на чужом проводе поле не проверяется. Строка доктора —
`doctor.extraBody.fastMode` в `base.json` и `en.json`. Тесты — `ExtraBodyConflictsTest.fast mode is named for opus 4-8 and allowed on opus 5-5`.

### `agents.json` — пресеты ACP-агентов (A6, A7)

```jsonc
{ "agent_servers": {
  "GitHub Copilot CLI": { "command": "copilot", "args": ["--acp"], "env": {} },
  "Junie": { "command": "junie", "args": ["--acp", "true"], "env": {} }
} }
```

Ограничения — комментарием в файле: `session/new` у Copilot принимает только рабочую папку и MCP-серверы, а фильтр инструментов и
reasoning фиксируются при запуске; BYOK — `COPILOT_PROVIDER_*` в `env`. Первоисточники:
`https://docs.github.com/en/copilot/reference/copilot-cli-reference/acp-server`, `https://junie.jetbrains.com/docs/junie-cli-acp.html`.
Kimi Code в сид не вносим: команда ACP в сводке не названа, а каталог реестра показывает её сам.
Antigravity — тоже нет: команды запуска сводка не называет.

### `hooks.json` — монитор выхода за разрешённые пути (D3)

```jsonc
{ "hooks": { "PreToolUse": [ { "id": "paths-outside-project", "command": "vibe-guard-paths", "failClosed": false } ] } }
```

Точное имя события и поля сверять со схемой `hooks` (`schemas/`): в наборе уже есть правила хуков, а `guard/CommandPaths` даёт
разбор пути. `failClosed: false` — пока режим не подтверждён первоисточником (D4). Повод — мониторы OpenAI, тревога примерно
через 30 минут после выхода агента из песочницы: `https://openai.com/news/` (по сводке 31.10).
