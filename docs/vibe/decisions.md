# Журнал решений VibeIDEA

Формат: дата — развилка → варианты → выбор → почему. Ночные (без владельца) помечены 🌙.

## 2026-08-23 🌙 — ночь основания

1. **Стартовый пак start0** → применять / нет → **нет** → форк готовой JVM-кодовой базы, а не новый веб-проект; пак (Point0+Prisma+better-auth) неприменим по стеку. Осознанное отступление от глобального правила.
2. **Глубина клона** → shallow / полный → **полный** → форку нужна история для merge с апстримом; shallow — полурешение, ломающее будущие синки.
3. **Remotes** → оставить origin=JetBrains / переименовать → **origin → upstream** → защита от случайного push в чужой репозиторий; свой origin появится решением владельца.
4. **Ветки** → master-only / main+next → **master = зеркало `upstream/master` (обновление только ff-merge из него), main = релизная, next = работа** → глобальная дисциплина main/next + явное место для «чистого апстрима» (синк-база).
5. **PHP/TS** → ждать открытых плагинов / LSP-стек → **LSP4IJ (EPL-2.0) + Phpactor (MIT) + vtsls (MIT) + vscode-js-debug/vscode-php-debug (MIT)** → единственный лицензионно чистый путь: плагины PhpStorm/WebStorm закрыты, Intelephense запрещает редистрибуцию (EULA §5c — проверено по тексту), открытых аналогов нет. `platform/lsp` (открыт 2026-06, Apache-2.0) — отслеживать как нативную замену языковых фич; DAP остаётся за LSP4IJ.
6. **Агентская обвязка** → реверс закрытого Claude-плагина / свой ACP-клиент → **свой ACP-клиент на Kotlin SDK `com.agentclientprotocol:acp`** → JetBrains-клиент закрыт (AI Chat), в IC его нет; ACP даёт весь парк агентов сразу; Claude — через официальный адаптер `claude-agent-acp`.
7. **Размещение своего кода** → правки платформы / оверлей → **оверлей: свои модули/плагины `com.vibe.*`**, правки платформы только с записью в FORK_CHANGES.md → урок VibeIDE: merge-налог на каждую правку апстрима вечен.
8. **Имя продукта** → «VibeIDEA» → **рабочее, не окончательное** → сходство с товарным знаком «IntelliJ IDEA»; решение за владельцем (вынесено в утренний отчёт).
9а. **Синк с апстримом** → по HEAD master / по тегам → **по тегам релизов** → master IC движется слишком быстро; теги — стабильные точки, обе стороны (IC и android) чекаутятся на один тег. Формат подтверждён фактом (`git ls-remote --tags`): `idea/2026.2.1`.

10. **Обрыв полного клона (curl 56 на 78%, потеряно ~1.5 ч)** → ретраить монолитный пак / shallow+деепен → **shallow `--depth 1` сразу + фоновая дозакачка истории кусками `--deepen` с ретраями, всё под `caffeinate -i`** → монолитный пак ~6 GB нерезюмируем, каждый обрыв обнуляет загрузку; кусочный деепен ретраится пошагово, а ночная работа не блокируется (рабочее дерево уже есть). Конечное состояние то же — полная история master (уточнение решения №2, не отмена).

11. **Коллизия с docs/ апстрима** → наши доки рядом с чужими в `docs/` / свой неймспейс → **`docs/vibe/`** → у IC уже есть `docs/`, и на case-insensitive APFS наш `README.md` молча перетёр их `readme.md` (восстановлен из git до коммита); оверлей-принцип распространён и на документацию.
