# ИНСТРУМЕНТЫ В ПРЯМОМ ЧАТЕ С МОДЕЛЬЮ — КАК НАЧАТЬ

> Мануал «как сделать». Прямой чат — это ход, когда в композере выбрана модель провайдера, а не ACP-агент.

---

## 1. Что это даёт

Модель в прямом чате сама пользуется инструментами IDE и общей памятью семейства VibeMemory.
Искать по проекту и читать память она может без вопросов.
Записать решение в журнал проекта, сохранить, изменить или удалить запись памяти — только после вашего «да» на этот конкретный вызов.

Инструменты IDE: кто импортирует файл и что он импортирует, как связаны два файла, где встречается имя, что проект уже записал по теме, какие решения приняты, записать решение, сведения о проекте.

ACP-агенты получают ту же память иначе: IDE передаёт им сервер в `session/new`, и вызывает его сам агент.

---

## 2. Что нужно заранее

- Установленный VibeMemory: `vibememory install` кладёт сервер в `~/.vibememory/bin/vibememory-mcp`
  Каталог движка в другом месте — переменная `VIBEMEMORY_DIR`
- Проверка: `~/.vibememory/bin/vibememory-mcp --version` отвечает версией
- Для инструментов IDE ничего ставить не нужно; VibeMemory нужен только для памяти
- Модель, которая принимает инструменты: у OpenAI-совместимых, Anthropic и Gemini это почти все современные модели

---

## 3. Шаги

1. Settings → Tools → VibeIDEA → Агент: галка «Инструменты в прямом чате с моделью» — включена по умолчанию
2. Там же «Раундов вызова инструментов за ход, не больше» — по умолчанию 8
3. Выбрать в композере модель провайдера и спросить, например: «Найди в памяти, на чём остановился поток pipelines-contract»
4. В ленте появится строка `🔧 memory_search`, затем ответ модели
5. Попросите сохранить запись — IDE спросит разрешение и покажет аргументы вызова

---

## 4. Как это устроено

- Сервер памяти запускается при первом ходе с инструментами и живёт, пока открыта панель чата
- Инструменты IDE — тот же каталог, что MCP-сервер IDE отдаёт внешним клиентам, кроме `vibe_run_agent`: он ставит задачу агенту той же панели, чей ход сейчас идёт
- Инструменты памяти — те, что объявил сервер: `memory_search`, `memory_get`, `history_search`, `project_resolve` читают; остальные считаются записью, в том числе новые, о которых IDE ещё не знает
- Выключатели записи и запуска у HTTP API прямой чат не касаются: там человека рядом нет, а здесь он спрашивается на каждый пишущий вызов
- В недоверенном проекте запись запрещена целиком, чтение разрешено
- Каждый вызов попадает в журнал аудита: имя инструмента, итог, длительность. Аргументы и результат не пишутся
- Обмен с инструментами хранится в истории треда вместе с ответом: на следующий вопрос модель помнит, что нашла. Результат длиннее 20 000 символов хранится обрезанным
- Инструментов больше порога (Settings → Tools → VibeIDEA → Агент, по умолчанию 20) — модель видит не все схемы, а инструмент `tool_search`: называет задачу, IDE находит до пяти подходящих, и они доступны до конца треда. В ленте строка `🔎 поиск инструментов`. Каждая загрузка меняет список инструментов и один раз сбрасывает кэш промпта
- Раунд — один запрос к модели. Модель вызывает инструменты подряд — каждый раунд оплачивается как запрос; на потолке ход останавливается со строкой в ленте

## 5. Если не работает

| Что видно | Причина | Что делать |
|---|---|---|
| Ничего не происходит, строк `🔧` нет | VibeMemory не установлен или галка выключена | Шаг 2 раздела «Что нужно заранее» |
| «сервер памяти не ответил» | Сервер установлен, но не запускается | `vibememory doctor`, затем перезапустить панель чата |
| «помечена квирком NO_TOOLS» | Модель в каталоге квирков отмечена как не принимающая инструменты | Взять другую модель или убрать квирк в `.vibe/modelQuirks.json` |
| «вызывает инструменты только через Responses API» | Модель (GPT-6 Astra) принимает инструменты только на эндпоинте `/v1/responses` | Объявить модели `"protocol": "openai-responses"` — спека `providersSpec.md` |
| «принимает инструменты только без рассуждения» | GPT-6 Sol или Luna на chat/completions: ход с инструментами уходит без рассуждения | То же объявление `"protocol": "openai-responses"` — там идут и рассуждение, и инструменты |
| Ход обрывается HTTP 400 со словом tools | Эндпоинт не умеет вызов функций | Добавить модели квирк `NO_TOOLS` — спека `modelQuirksSpec.md` |
