# Живая проверка: что подтверждается только руками

Тесты и гейты закрывают логику, но не видят того, что человек видит и нажимает: всплывашку под
мышью, вставку из чужого приложения, машину с другим менеджером Node, корпоративный прокси. Этот
файл — очередь таких проверок.

Пункт живёт здесь, пока его не проверили руками. Проверенный вычёркивается из файла, а итог
записывается строкой в [roadmap](../roadmap.md): «проверено руками, дата». Не прошёл — пункт
остаётся, рядом строка с тем, что увидели, и задача в roadmap.

Регламент на каждый выпуск — отдельно: [acpSmoke.md](acpSmoke.md). Здесь — разовые проверки новых
возможностей, по сборкам.

## Как проверять

1. Образ — из комплекта рядом с репозиторием (`../VibeIDEA-release-X.Y.Z`), а не из `out/`.
2. Открыть проект, в котором есть `.vibe/`: сиды засеваются при открытии.
3. Не прошло — номер пункта и строка из ленты или снимок экрана: этого достаточно.
