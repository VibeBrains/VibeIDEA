# Отладка TypeScript и PHP

VibeIDEA поставляет **клиента** отладки (LSP4IJ умеет Debug Adapter Protocol), а сам адаптер —
внешняя программа, ровно как языковой сервер. Причина та же: адаптеры распространяются через npm и
composer, и бандлить их значит тащить чужой рантайм и его лицензию.

## Проверить, что есть

Tools → **«VibeIDEA: языковые серверы»** — отчёт показывает и серверы, и отладчики, и для
недостающего даёт однострочную команду установки.

## Поставить адаптер

```bash
npm install -g js-debug-adapter
```

```bash
composer global require xdebug/vscode-php-debug
```

После установки IDE нужно перезапустить: PATH читается при старте процесса.

## Подключить

Settings → Languages & Frameworks → **Debug Adapter Protocol** → добавить сервер, указать
установленный бинарь и создать конфигурацию запуска. Дальше точки останова, шаги и просмотр
переменных работают штатными средствами IDE.

## Почему так, а не «всё из коробки»

Вкомпилировать адаптер значило бы:

- везти чужой рантайм внутри дистрибутива и отвечать за его обновления;
- принять его лицензию за пользователя;
- вырасти в размере на десятки мегабайт ради того, что нужно не каждому.

Взамен мы делаем отсутствие адаптера **видимым**: молчание — худший из возможных ответов, потому что
не называет ни причины, ни того, что делать.
