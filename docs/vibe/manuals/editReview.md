# Разбор правок агента по одной

Агент изменил файл в нескольких местах. Каждое место — отдельная правка, и решать их можно по одной,
прямо в редакторе: не обязательно принимать или отклонять файл целиком.

## Как начать

1. Дождитесь, пока агент запишет файлы. Полоска над полем ввода в чате покажет число изменённых файлов.
2. Откройте список изменений в чате и нажмите у файла «Разобрать по одной правке». Файл откроется на первой правке.
   Можно и открыть изменённый файл обычным способом: разбор появится в нём сам.
3. Правки подсвечены в тексте. Над каждой — «Принять» и «Отклонить» и строки, которые агент убрал.
4. Внизу редактора панель: «Правка N из M», «Файл K из L», стрелки по правкам и файлам, «Принять файл», «Отклонить файл».

## Что делает каждое решение

- **Принять правку** — текст остаётся как есть, правка перестаёт быть вопросом.
- **Отклонить правку** — строки возвращаются к состоянию до агента. Это одна команда редактора, её отменяет `Ctrl+Z`.
- **Принять файл**, **Отклонить файл** — то же для всех оставшихся правок файла разом.
- Файл, который агент создал, — одна правка на весь файл. Отклонить её значит удалить файл.

Решена последняя правка файла — открывается следующий файл с правками.

## Куда переходит ход

После «Принять» или «Отклонить» текущей становится правка, которая стояла следом за решённой.
Решена последняя — текущей становится предыдущая. Ни одна правка не проскакивается: неважно, нажата
кнопка на самой правке или клавиша.

Экран прокручивается, только если следующая правка вне экрана. Видимая остаётся на месте.

Если агент ещё пишет и записал файл заново, разбор начинается с первой правки.

## Клавиши

| Действие | Клавиши |
|---|---|
| Следующая правка | `Ctrl+Alt+Shift+]` |
| Предыдущая правка | `Ctrl+Alt+Shift+[` |
| Принять правку | `Ctrl+Alt+Shift+Enter` |
| Отклонить правку | `Ctrl+Alt+Shift+Backspace` |

Клавиши работают только в файле, где идёт разбор. Те же действия есть в меню мозга, группа «Агент».

## Что стоит знать

- Принятие правки — запись в журнале правок, а не изменение текста: `Ctrl+Z` его не отменяет.
- Если отклонить последнюю правку и вернуть её через `Ctrl+Z`, текст вернётся, а разбор — нет: журнал этот файл уже отпустил.
- Слишком большая пара «до и после» показывается одной правкой на весь файл.
- Список изменений в чате остался быстрым путём: принять или отклонить файл целиком можно оттуда.
- Записи ACP-агентов идут через окно подтверждения до записи; разбор по правкам к ним не относится.
