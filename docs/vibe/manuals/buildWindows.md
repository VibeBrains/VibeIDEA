# Сборка на Windows

Одна команда:

```bat
vibeidea-build.bat
```

Скрипт делает три шага в правильном порядке — зависимости по закреплённым версиям, сборка,
подсказка про проверку. Порядок, который надо помнить, однажды выполняют наполовину.

## Что нужно на машине заранее

| Что | Зачем | Проверка |
|---|---|---|
| Git и клон `android\` | без него инсталлятор не собирается | `getPlugins.bat` |
| Node.js 18+ | им ставятся языковые серверы, им же запускаются отладчики | `node -v` |
| ~100 ГБ на диске | сборка распаковывает платформу целиком | — |

JDK и Bazel **ставить не нужно**: тулчейн герметичный, они скачиваются сами.

PHP нужен только для работы IDE (языковой сервер PHP), для сборки — нет.

## Что получится

`out\vibeidea\artifacts\` — инсталлятор `.exe` и архив `.win.zip`.

## Проверить собранное

```bat
powershell -ExecutionPolicy Bypass -File vibe-plugins\tools\checkVibeDist.ps1
```

Гейт распаковывает архив во временную папку и проверяет то, чего не видит ни один юнит-тест:
вписаны ли готовые плагины в индекс `plugin-classpath.txt` (каталог в `plugins\` сам по себе не
значит ничего), доехали ли библиотеки внутрь наших плагинов, лежат ли языковые серверы и адаптеры
отладки — и, главное, **запускаются** ли они. Проверка запуска пропускается, если на машине нет
Node, и об этом говорится вслух, а не молчанием.

## Почему два файла, а не один «универсальный»

`vibeidea-build.sh` для macOS и Linux, `vibeidea-build.bat` для Windows. Апстримовские `.cmd`
сделаны двойными — bash и батник в одном файле, — но такой файл нельзя проверить ни `sh -n`, ни
глазами: половина синтаксиса всегда мусор для того, кто его читает. Для сборочного скрипта
проверяемость важнее краткости.

## Версии внешних артефактов — в одном месте

`vibe-plugins\deps\pins.env` — единственный источник версий и хешей LSP4IJ, Phpactor и двух
отладочных адаптеров. Его читают оба скрипта загрузки (`download.sh` и `download.ps1`) и оба
гейта. Пока версии жили в теле sh-скрипта, второй скрипт означал бы вторую копию тех же чисел, а
копия версии расходится не «если», а «когда» — и расходится молча: обе сборки успешны, содержимое
разное.

## Чего мы не проверяли

Скрипты написаны, но **на Windows не прогонялись**: под рукой только macOS. Это первое, что стоит
сделать на живой машине; если что-то упадёт, вывод скриптов называет шаг и причину.
