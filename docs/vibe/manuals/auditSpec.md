# Спека формата `.vibe/audit.jsonl` — журнал аудита агента (VibeIDEA)

← [Дерево документации](../README.md)

> **Как этим пользоваться:** этот файл описывает формат журнала, который VibeIDEA пишет сама. Скормите его своей LLM, чтобы получить парсер/дашборд по логу, или читайте сами — одна строка = одно событие. Файл вы не создаёте руками.

## Что это

`.vibe/audit.jsonl` — append-only журнал действий агента: промпты, ответы, вызовы инструментов, запросы разрешений, записи файлов, срабатывания хуков и гейтов, открытие/снятие предохранителей. По умолчанию **выключен** — включается в Settings → Tools → VibeIDEA → **Агент** → «Вести журнал аудита». Off по умолчанию сознательно: журнал — это поверхность безопасности/телеметрии, она должна быть добровольной.

## Приватность (что НЕ пишется никогда)

Аргументы инструментов, тела команд, поисковые запросы и содержимое файлов **не попадают в журнал никогда**. Единственное исключение — целевой путь файловых инструментов, обрезанный до 260 символов. У командных инструментов (`run_command`, `Bash` и т.п.) не пишется даже путь — их аргумент и есть чувствительная часть.

## Формат

JSONL: одна строка — один JSON-объект, завершённый `\n`.

```json
{"ts":1730000000000,"action":"tool_call:done","ok":true,"files":["src/App.kt"],"meta":{"tool":"edit_file","status":"completed"}}
```

| Поле | Обязательное | Значение |
|---|---|---|
| `ts` | да | Unix-время в миллисекундах — единственный таймстемп записи |
| `action` | да | Тип события (закрытый список ниже) |
| `ok` | да | Успех/неуспех события (boolean) |
| `files` | нет | Массив путей (для файловых действий; каждый ≤ 260 символов). Пустой массив опускается |
| `model` | нет | Модель/агент в формате `acp/<имя>` |
| `latencyMs` | нет | Длительность (для `reply`) |
| `meta` | нет | Плоский объект `строка→строка` с деталями события |

### Значения `action`

| action | Когда | Заметное `meta` |
|---|---|---|
| `prompt` | Отправлен промпт агенту | `chars` |
| `reply` | Получен ответ (конец хода/бонса) | `stopReason` или `error` |
| `tool_call:start` | Агент начал вызов инструмента | `tool`, `status` |
| `tool_call:done` | Вызов завершился | `tool`, `status` |
| `permission` | Запрос разрешения | `title`, `outcome` (`selected`/`cancelled`) |
| `fs_write` | Запись файла через клиента | — (путь в `files`) |
| `hook` | Отработала цепочка хуков | `event`, `tool`, `blocked`, `broken` |
| `verify_gate:result` | Прогон VERIFY-GATE | `ran`, `exit` |
| `turn_check:result` | Проверки хода нашли проблемы | `findings`, `mode` |
| `circuit_breaker_opened` | Сработал защитный предохранитель | `breaker`, `reason` |
| `circuit_breaker_recovered` | Пользователь снял предохранители | `cleared` |
| `terminal` | Завершение/гейт терминала | `exit` или `gate`/`reasons`/`approved` |
| `checkpoint` | Снят чекпоинт | `hash` (первые 12 символов) |

## Ротация

Ротация **по размеру**: настройка «Ротация журнала, МБ» (по умолчанию 10, диапазон 1–1000). Перед записью, если файл превысил бы порог, текущий `audit.jsonl` сжимается gzip в `audit.<N>.jsonl.gz` (N — первый свободный номер с 1), а основной файл начинается заново.

## Удаление

Журнал — обычный файл; удалите `.vibe/audit.jsonl` (и `audit.*.jsonl.gz`) вручную, чтобы стереть историю. Запись под работающей IDE переживает удаление: следующий флаш создаст файл заново, если аудит включён.
