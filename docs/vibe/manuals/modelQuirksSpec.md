# Спека формата: `.vibe/modelQuirks.json`

> **Скопируйте этот файл целиком своей LLM и попросите собрать `.vibe/modelQuirks.json` для вашей
> модели.** Документ самодостаточен: ни исходники, ни интернет для этого не нужны.

## Что это за файл

Каталог **причуд моделей** — того, что конкретная модель отказывается принимать в запросе.

Каждый вендор называет свой протокол «совместимым с OpenAI», и каждый совместим до определённого
предела. Рассуждающая модель отвергает `temperature`, переименовывает `max_tokens`, не принимает
системную роль или отказывается стримить. Отказ приходит как HTTP 400 с фразой про
неподдерживаемый параметр — в чате это выглядит ровно как «модель сломалась».

У VibeIDEA есть **вшитый** каталог таких причуд. Он неизбежно отстаёт: вендор ломает совместимость
во вторник и чинит в пятницу. Этот файл — способ не ждать релиза IDE.

## Где лежит и когда читается

| Путь | Роль |
|---|---|
| `<проект>/.vibe/modelQuirks.json` | правила этого репозитория — едут вместе с ним |
| `~/.vibe/modelQuirks.json` | ваши правила для всех проектов |
| (вшитый каталог) | база, работает без единого файла |

Файл проекта сильнее глобального, оба сильнее вшитого. Правка подхватывается **на лету** —
перезапуск IDE не нужен. Формат — JSONC: разрешены `//`-комментарии и висячие запятые.

## Структура

```jsonc
{
  "models": [
    {
      "match": "^gpt-5",          // обязательное: регулярное выражение по id модели
      "quirks": [],               // обязательное: список причуд, пустой = «причуд нет»
      "note": "починили 2026-09"  // необязательное: попадает в лог IDE
    }
  ]
}
```

- **`match`** — регулярное выражение (синтаксис Java/Kotlin), проверяется поиском подстроки по id
  модели. Префикс вендора отбрасывается: `openai/o1-mini` и `o1-mini` — одна и та же модель, и
  правило `^o1-mini` подойдёт к обеим записям.
- **`quirks`** — список имён из таблицы ниже. **Поле обязательно**: запись без него игнорируется
  целиком, потому что молчание — не то же самое, что «причуд нет».
- **`note`** — свободный текст для лога; на поведение не влияет.

## Список причуд

Других имён нет; незнакомое имя пропускается с предупреждением (более новая IDE может знать больше).

`NO_SAMPLING` — агрегат трёх точных имён, а не синоним одного из них. Берите точное имя, когда
модель отвергает **не всё**: MiniMax, например, принимает `temperature` и `top_p` и игнорирует
только `top_k`, и описать его агрегатом значило бы молча отобрать две настройки, которые работают.

| Имя | Что означает | Что делает IDE |
|---|---|---|
| `NO_SAMPLING` | модель сама решает, насколько быть творческой | убирает `temperature`, `top_p`, `top_k` |
| `NO_TEMPERATURE` | отвергается только `temperature` | убирает `temperature` |
| `NO_TOP_P` | отвергается только `top_p` | убирает `top_p` |
| `NO_TOP_K` | отвергается только `top_k` | убирает `top_k` |
| `MAX_COMPLETION_TOKENS` | лимит ответа называется иначе | переименовывает `max_tokens` → `max_completion_tokens`, **сохраняя значение** |
| `NO_SYSTEM_ROLE` | системная роль не принимается | системный промпт уезжает первым сообщением пользователя, а не теряется |
| `NO_STREAMING` | ответ по частям не отдаётся | не просит стрим, ждёт ответ целиком |
| `NO_STOP` | стоп-последовательности отвергаются | убирает `stop` |

## Главное правило приоритета

Запись файла **замещает** вшитое правило для подошедших моделей, а не добавляется к нему.

Это сделано ради одной строки, без которой файл был бы бесполезен:

```jsonc
{ "match": "^gpt-5", "quirks": [] }
```

Так снимается ошибочное или устаревшее вшитое правило — «эта модель больше не капризничает,
перестань переписывать мой запрос». Если бы записи складывались, снять вшитое было бы нечем.

## Что происходит при ошибках

| Ситуация | Поведение |
|---|---|
| файла нет | ровно прежнее поведение, вшитый каталог |
| файл не разобрался целиком | предупреждение в ленте, каталог остаётся вшитым |
| одна запись битая | пропускается с предупреждением, остальные работают |
| `match` — не регулярное выражение | запись пропускается с предупреждением |
| нет поля `quirks` | запись пропускается: молчание ≠ «нет причуд» |
| неизвестное имя причуды | пропускается только оно, остальные из этой записи применяются |

## Как проверить, что сработало

Tools → **«VibeIDEA: диагностика»**, строка **«Причуды модели»**: она называет модель, список
применённых причуд и **источник** — `modelQuirks.json` или `built-in`. Это единственный
достоверный ответ на вопрос «почему у меня пропала temperature».

## Полный пример

```jsonc
{
  "models": [
    // вендор починил API — возвращаем себе temperature
    { "match": "^gpt-5", "quirks": [], "note": "с 2026-09 принимает temperature" },

    // корпоративный прокси без SSE
    { "match": "^internal-llm", "quirks": ["NO_STREAMING", "NO_STOP"] },

    // новое рассуждающее семейство, о котором IDE ещё не знает
    { "match": "^(o5|r2)(-|$)", "quirks": ["NO_SAMPLING", "MAX_COMPLETION_TOKENS"] }
  ]
}
```
