# Языковые серверы: TypeScript и PHP

Как включить полноценную работу с TypeScript и PHP в VibeIDEA. IDE несёт LSP-клиент (LSP4IJ) и плагин-регистратор из коробки; сами серверы — внешние программы, их надо поставить один раз.

## TypeScript — vtsls

Требуется Node.js ≥ 18.

```bash
npm install -g @vtsls/language-server
```

Проверка: `vtsls --version`. VibeIDEA ищет `vtsls` в PATH и типовых местах (`~/.npm-global/bin`, `/opt/homebrew/bin`, `/usr/local/bin`, `~/.local/bin`).

## PHP — Phpactor (в комплекте)

**Ставить ничего не нужно**, если на машине есть PHP 8.1+: phar едет вместе с IDE и запускается на
вашем интерпретаторе. Свой Phpactor, если он установлен, всегда сильнее встроенного — так проект,
прибитый к другой версии, не ломается о нашу.

Ниже — как поставить свой, если он нужен именно свой.

## PHP — свой Phpactor

Требуется PHP ≥ 8.1.

```bash
mkdir -p ~/.local/bin && curl -Lo ~/.local/bin/phpactor https://github.com/phpactor/phpactor/releases/latest/download/phpactor.phar && chmod +x ~/.local/bin/phpactor
```

`~/.local/bin` вместо `/usr/local/bin` — чтобы не требовалось `sudo`; эта папка входит в список,
который IDE просматривает сама (GUI-приложение на macOS не наследует PATH оболочки).

**`brew install phpactor` не работает** — такой формулы нет, и мы сами раздавали эту команду до
31.08.2026. Команда, которая падает, хуже отсутствующей: человек делает вывод, что сломана вся
поддержка языка.

Проверка: `phpactor --version`. Ищется так же (плюс `~/.composer/vendor/bin`).

## Фронт: TypeScript, Angular, Tailwind, SCSS/Sass, CSS и ESLint (в комплекте)

**Ставить ничего не нужно**, если на машине есть Node: серверы едут с IDE и запускаются на нём.
Свой сервер, если он установлен, всегда сильнее встроенного.

Ниже — как поставить свой.

## Фронт: свои серверы

```bash
npm install -g vscode-langservers-extracted
```

Пакет несёт четыре сервера, мы подключаем **два**:

- **CSS и LESS** — фронтовые языки, которых в IntelliJ Community нет вовсе;
- **ESLint** — интеграции с ним в Community тоже нет. Сервер исполняет конфиг ПРОЕКТА: там, где
  ESLint не настроен, он честно молчит — придумывать правила, о которых проект не просил, хуже
  тишины.

**SCSS и Sass обслуживает не он, а Some Sass** (`npm install -g some-sass-language-server`):
общий CSS-сервер живёт в одном файле, и переход по переменной из соседнего `@use` у него никуда не
ведёт. `.scss` и `.sass` отданы Some Sass целиком — два сервера на одном файле удвоили бы подсказки.

**Angular** — `npm install -g @angular/language-server`: переход из тега шаблона в компонент,
автодополнение компонентов и пайпов, проверка типов шаблона. Ищет TypeScript по probe-путям, и мы
подставляем их сами: сперва проект, потом наш набор.

**Tailwind** — `npm install -g @tailwindcss/language-server`: подсказка классов в разметке, цвет
рядом с классом, объяснение `@apply`. Поднимается **только** там, где проект действительно на
Tailwind: есть `tailwind.config.*` или пакет `tailwindcss` в `package.json`.

**HTML и JSON из того же пакета намеренно НЕ подключены**: платформа обслуживает их сама
(плагины `html-tools` и `json` в комплекте), а два движка на одном файле дают два набора подсказок
и два набора диагностик, половина которых спорит с другой.

**Stylus** — `npm install -g stylus-lsp`: третий диалект CSS рядом с Sass и LESS. Стартует только
на `.styl`, поэтому проект без Stylus не платит за него ничем.

**Диалекты PostCSS** (`.pcss`, `.postcss`, `.sss`) обслуживает общий CSS-сервер: это тот же CSS,
только с плагинами, и своего сервера у них нет. Без этого сопоставления их файлы не обслуживал
никто.

Чего в наборе нет и почему: **Vue/Svelte/Astro** (каждый со своим сервером — заводим, когда
появится проект, где это нужно).

Прежняя причина не брать Tailwind — «стартовал бы вхолостую в каждом проекте» — снята 18.09.2026
тем, что сервер поднимается только по признакам самого проекта.

## Что получится

Открой `.ts`/`.tsx`/`.js` или `.php` файл — сервер стартует сам (LSP4IJ: консоль и статус — в тулвиндоу «Language Servers»). Работают: completion, диагностика, go to definition, find references, hover, форматирование. Подсветка — TextMate-грамматики из комплекта.

## Если сервер не стартует

Тулвиндоу «Language Servers» → выбрать сервер → вкладка Logs: в ошибке будет ровно то имя бинаря, которое не нашлось. Поставь его или пропиши абсолютный путь в Settings → Languages & Frameworks → Language Servers.

## Премиум-путь для PHP (по желанию)

Intelephense мощнее Phpactor (переименования, inlay hints — в платном tier), но его лицензия запрещает поставку в составе IDE — ставится самостоятельно: `npm i -g intelephense`, затем добавить сервер в LSP4IJ вручную (command: `intelephense --stdio`) и принять его EULA.

## Встроенный сервер стареет

Версии серверов в комплекте закреплены в `vibe-plugins/deps/download.sh` и
`vibe-plugins/deps/servers-npm/package.json` — то есть **встроенный сервер стареет вместе с релизом
IDE**, а не обновляется сам. Это осознанный размен: закреплённая версия одинакова у всех и не
ломается в понедельник от чужого релиза.

Нужна свежая версия — поставьте её себе обычным способом (`npm install -g …`, phar из релизов
Phpactor). **Свой сервер всегда сильнее встроенного**, поэтому никаких переключателей трогать не
надо: как только бинарь появился на машине или в PATH, IDE берёт его. Кто именно работает сейчас,
говорит доктор: Tools → «VibeIDEA: языковые серверы».

Лицензии всех поставляемых серверов перечислены в отчёте о третьих лицах, который едет вместе с
дистрибутивом (`license/third-party-libraries.html`).
