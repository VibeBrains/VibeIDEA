# Тело запроса видит только заглушка сервера

**[архитектура+правило]**

## Контекст

25.09.2026 VibeIDE нашёл у себя потерю системного промпта.
Адаптер AI SDK выбрасывал сообщения с ролями `system` и `developer`, и модель работала без системного промпта.
Тесты сборки промпта были зелёными: тела запроса ни один из них не видел.
Потерю нашла заглушка провайдера, которая записывает тела запросов.

У нас SDK нет: тело собирает `LlmClient` на каждом из четырёх проводов.
Но и у нас тела не видел ни один тест.
Сборка тела живёт внутри `LlmClient.chat`, а он читал три настройки IDE из `PropertiesComponent`, которого в юнит-тесте нет:
офлайн-режим, уровень рассуждения и маршрут через прокси.

## Суть

Две точки подмены, поведение по умолчанию прежнее:

- `LlmSettings` — офлайн-режим и уровень рассуждения; `LlmSettings.Ide` читает живые настройки на каждом запросе
- `ProviderRoutes` — какой `HttpClient` везёт запрос; его реализует `ProviderClients`

`WireBodyTest` поднимает `HttpServer` на 127.0.0.1 и отвечает пустым потоком `data: [DONE]`.
На таком ответе все четыре провода кончают ответ без ошибки.
Заглушка записывает путь, заголовки ключа и тело.

Что проверено на проводе 25.09.2026:

| Провод | Где системный промпт |
|---|---|
| anthropic | поле `system`, два системных сообщения склеены переводом строки |
| openai | сообщения с ролью `system` на своих местах в списке |
| openai-responses | поле `instructions` |
| gemini | `systemInstruction.parts[0].text` |
| модель с причудой `NO_SYSTEM_ROLE` | первое сообщение пользователя, склейка через пустую строку |

Тот же тест держит офлайн-режим по `runsLocally`: запрос к прокси на localhost с `"runsLocally": false` до заглушки не доходит.

## Применение

- Новый провод, новая роль сообщения, новое поле тела — ещё и кейс в `WireBodyTest`.
- Настройку, которую читает запрос, заводить в `LlmSettings`.
  Прямой вызов `VibeAgentSettings` изнутри `LlmClient` снова сделает тест провода невозможным.
- Заглушка отвечает пустым потоком.
  Если провод начнёт требовать от ответа большего, например падать без `response.completed`, тест скажет об этом первым.
