# Свои команды агента в меню «/»

**[грабли]**

## Контекст

ACP-агент объявляет свои слэш-команды уведомлением `available_commands_update` (ACP v1, slash commands).
Клиент его не обрабатывал: команды Claude Code и Codex в меню не попадали.

## Суть

- **Команда работает, только если стоит в начале промпта.** Ход ACP ставит перед текстом свои вводные блоки — правила проекта, знания, дизайн, перенесённый план. Набранная `/review` уходила бы не первым словом, и агент принял бы её за текст. Команда агента теперь уходит как есть, без вводных.
- **Совпадение имён.** На слове, занятом командой IDE, срабатывает команда IDE: строка агента видна, но слово не вставляет — иначе меню обещало бы одно, а происходило бы другое.
- Список живёт у сессии и может прийти заново в любой момент: агент узнаёт свои команды по ходу загрузки.
- Меню берёт список в момент открытия у текущей сессии, а не получает рассылкой: пикеров режима и тумблеров, которым рассылают состояние, десяток мест, и ещё одна рассылка разошлась бы с ними.

## Как применять

- Разбор — `AgentCommand.parse`, проверка «первое слово — команда» — `AgentCommand.of`; сквозной тест — сценарий `commands` фальшивого агента.
