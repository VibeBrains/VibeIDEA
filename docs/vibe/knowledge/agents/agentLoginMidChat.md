# Вход агента истёк посреди разговора

**[инцидент]**

## Контекст

Claude Agent (`@agentclientprotocol/claude-agent-acp`) посреди чата отвечал текстом «Failed to authenticate: OAuth session expired and could not be refreshed», а запрос кончался ошибкой `{"code":-32000,"message":"Authentication required"}`.
Лента показывала только строку «[ошибка агента]», и человек не знал, как войти.

## Суть

- **Диалог входа жил только на старте сессии.** `AgentLoginDialog` открывался, когда не открывалась сессия; сбой самого `session/prompt` шёл в общую ветку ошибок.
- **Способы входа были на месте.** Возможность `auth.terminal` клиент объявляет в `initialize`, поэтому адаптер отдаёт терминальные способы (`claude-ai-login`, `console-login`; на удалённой машине - `claude-login`). Пустой список способов тут не причина.
- **Сбой узнаётся по коду и по словам.** `AgentAuth.needsLogin`: код -32000 под любым числом обёрток, либо слова «Authentication required», «Failed to authenticate», «OAuth session expired». Код теряется, когда ошибку пересказывает обёртка, а слова остаются.
- **Терминальный способ идёт во вкладке Терминала.** Команда - из `_meta["terminal-auth"]` (адаптер присылает её клиенту, объявившему этот флаг), иначе команда записи агента плюс аргументы способа. Терминал - опциональная зависимость, без него команда показывается для копирования.
- **После входа агент запускается заново**, как требует спека для терминального входа; сообщение человек отправляет ещё раз.
