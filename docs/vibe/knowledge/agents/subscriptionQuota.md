# Остаток подписки у вендоров: чему верить (VibeIDEA)

← [Индекс базы знаний](../README.md)

## Суть

Остаток подписки показывается только по ответу вендора (решение №97).
Своим подсчётом его не получить: кредиты пересчитываются по правилам вендора, а расход вне IDE тем же ключом не виден.
Сверено 17.09.2026.

## MiniMax Token Plan

- **Запрос официальный, поля — нет.**
  `GET https://api.minimax.io/v1/token_plan/remains` назван в platform.minimax.io/docs/token-plan/faq, смысл полей там не описан.
- **Единственный авторитет — CLI самого вендора** (github.com/MiniMax-AI/cli):
  - `src/types/api.ts` — поля;
  - `src/utils/quota.ts` — их прочтение;
  - `test/fixtures/quota-response.json` — пример ответа.
- **Грабли: `*_usage_count` поменял смысл.**
  В старых ответах там остаток, в новых может быть израсходованное.
  CLI выбирает прочтение по `*_remaining_percent`, если процент есть.
  Если ни одно прочтение не сходится с процентом в пределах 1 — не показывает ничего.
  Если процента нет — остаётся старое прочтение «остаток».
  Слух «`usage_percent` означает остаток» из сторонних клиентов — пересказ этой же неоднозначности.
- `*_status` 3 — без ограничения; оба окна со статусом 3 и нулевыми итогами — модели нет в плане.
- Недельный процент умножается на `weekly_boost_permille / 1000`, поэтому остаток бывает больше 100%.
- Хосты вендора: `api.minimax.io` (международный), `api.minimaxi.com` (Китай) — `src/config/schema.ts` CLI.

## Z.ai GLM Coding Plan

- **Запрос не документирован.**
  `GET https://api.z.ai/api/monitor/usage/quota/limit` читают CodexBar, openclaw и onWatch.
  Z.ai в docs.z.ai/devpack/faq отправляет смотреть остаток в кабинет.
- **Грабли: формат уже менялся.**
  В сентябре 2026 у тарифа Lite окна пришли типом `CREDIT_LIMIT` вместо `TOKENS_LIMIT` (сырой ответ — github.com/onllm-dev/onWatch/issues/122).
  Клиенты, знавшие только старые типы, показывали 0.
  Незнакомый тип у нас — «не удалось прочитать», а не 0.
- `percentage` — израсходовано, целое.
  `unit`: 5 — минуты, 3 — часы, 1 — дни (CodexBar, openclaw).
  6 — неделя: вывод по сырому ответу (`unit 6, number 1` рядом с `unit 3, number 5`), вендором не подтверждён.
- `TIME_LIMIT` — месячный лимит MCP-инструментов, а не окно плана.
- Заголовок: CodexBar и openclaw шлют `Bearer`, один сторонний плагин — ключ без префикса; взято большинство.
