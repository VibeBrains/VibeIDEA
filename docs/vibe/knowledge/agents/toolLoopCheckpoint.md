# Цикл инструментов прямого чата: контрольные точки и продолжение с места

## Симптом

MiniMax M3.1 на Anthropic-совместимом API, режим «Автопилот», задача «выполни эту правку» в конфиге TypeScript.
Каждый ход модель читала файлы и звала grep, упиралась в «Модель вызывала инструменты 8 раз подряд — ход остановлен на потолке».
На «продолжи» новый ход начинал с того же `vibe_read_file` того же `config.ts`, и до правки дело не доходило три хода подряд.
Половина раундов каждого хода уходила на `tool_search`.

## Причины

1. **Ход без слов терял свои раунды.**
   `finishAgentBubble` пишет ход, не давший ни слова, записью `Role.OTHER` («ход закончился без единого слова») — вместе с раундами.
   Сборка запроса фильтровала `role != Role.OTHER`, и запись уходила целиком, с вызовами и результатами.
   Модель, которая работает молча (мысль в `thinking`, вызовы без текста), так видела каждый следующий ход с нуля.
   Ход, где модель что-то сказала, раунды сохранял: запись `ASSISTANT` проходила фильтр.
2. **Потолок 8 был обрывом, а не вопросом.**
   Правка конфига — это несколько чтений, поиск и сама правка; восьми раундов, половина из которых поиск инструментов, не хватало.
3. **Поиск инструментов считался работой.**
   Раунд из одних `tool_search` тратил потолок, не сделав ничего.
4. **Расход хода считался максимумом, а не суммой.**
   Цикл сливал использование раундов через `TokenUsage.merge` — правило для событий ОДНОГО ответа, где поле повторяет нарастающий итог.
   Ход из двадцати раундов учитывался как самый крупный из них, и бюджет автопилота по этому числу не сработал бы никогда.
   А ход без слов не записывал расход вовсе: `recordTurnSpend` звался только для записи `ASSISTANT`.

## Что делает VibeIDE

- Жёсткий потолок `vibeide.agent.maxLoopIterations`: при достижении прогон обрывается без вопроса; верхняя граница 200.
  Умолчание у него в двух регистрациях разное — 30 и 0; замысел коммита «full-autonomy defaults» — 0, без жёсткого обрыва.
- Мягкая точка `softCheckpointIterations`: прогон встаёт и спрашивает «Продолжить / Остановить», и «Продолжить» ведёт тот же прогон.
  При включённом автопилоте — 0, без пауз; выключение автопилота ставит 25.
- Токеновая точка `softCheckpointTokens` (1 000 000) спрашивает так же, но только когда включена точка по шагам.
- Сообщения `role: tool` с результатами лежат в треде и уходят в каждый следующий запрос; подрезка — по весу под окно, последний обмен не трогается.
- Повтор при сетевом сбое — 3 повтора, 1 → 5 с.

## Решение

- `TranscriptWire` собирает запрос из записей треда: запись `OTHER` с раундами уходит ответом модели, её текст — модельный `wireText`, а не строка ленты.
  Тем же предикатом `carried` считает позиции сжатие истории, иначе закреплённые сообщения съехали бы.
- `ToolLoopCheckpoint` — чистая логика точки: каждые N рабочих раундов (дефолт 25, 0 — не спрашивать) `ASK`, на автопилоте `PASS_ON_AUTOPILOT`, пока отрезок в бюджете `autopilotMaxTokens`.
  «Продолжить» сдвигает отсчёт бюджета на потраченное: человек сказал своё, как и своим сообщением.
  Раунд из одних `tool_search` не считается; жёсткий предел 200 считает всё.
- Точка проверяется ПОСЛЕ результатов раунда, ДО следующего запроса: остановка не оплачивает ответ, вызовы которого выполнены не будут.
- Остановленный ход кладёт в запись `wireText` с пометкой для модели (`stoppedMarker`: клиент остановил ход, задача не закончена, результаты выше актуальны) и строку в ленте с кнопкой «Продолжить».
- Найденные поиском инструменты восстанавливаются из раундов треда на всех проводах, а не только там, где их добавляют на месте.
- Расход хода — `TokenUsage.plus`, сумма запросов; ход без слов с известным расходом записывается в отчёт и в отрезок автопилота.
- TLS-сбой «Remote host terminated the handshake» — `SSLHandshakeException`, то есть `IOException`: `RetryPolicy` уже считает его временным и повторяет трижды с паузами 1, 2, 4 с, как VibeIDE. Закреплено тестом; ошибка в ленте означает, что провайдер не ответил и на повторах.

## Гейты

`TranscriptWireTest` воспроизводит случай: ход без слов с двумя раундами, остановленный клиентом, затем «продолжи» — запрос несёт оба вызова и оба результата, на Anthropic-проводе блоками `tool_use`/`tool_result`, на OpenAI-совместимом — `tool_calls` и сообщениями `role: tool`.
`ToolLoopCheckpointTest` — точки, автопилот в бюджете и за ним, поиск не в счёт, жёсткий предел.
Живьём на MiniMax не прогнано ⚠ перепроверить.
