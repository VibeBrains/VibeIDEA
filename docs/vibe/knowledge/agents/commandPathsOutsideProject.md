# [правило] Путь вне проекта в аргументе команды агента

**Контекст.** 11.11.2026 агент VibeIDE выполнил `npm run compare:brandbook -- --save /VolumES`;
скрипт по `--save` чистил каталог целиком, а macOS не различает регистр — `/VolumES` = `/Volumes`,
и внешний диск стёрся. Проверка по тексту строки удаления не видела: удаление внутри скрипта,
а путь в аргументе никто не смотрел.

**Суть.** Опасен не текст команды, а то, куда указывает путь в её аргументе. `guard/CommandPaths`
разбирает путь у любой программы: `--opt=/path`, `-o/path`, `~`, `$HOME`, `..`, Windows-диски и UNC;
на macOS и Windows сравнение без регистра; корень тома (`/`, `/Volumes`, `/Volumes/<том>`), домашняя
папка, корни `C:\` и `\\server\share`, а также корень проекта — всегда вопрос. Неразбираемая
переменная (`$ARCHIVE`) — тоже вопрос: неизвестное не считается безопасным. Читающие программы
(`cat`, `grep`, `find`, `ls`…) и scratch-папки (`/tmp`, `TMPDIR`, `/dev`, `/proc`, `/sys`) молчат,
иначе обычный `cat /etc/hosts` учил бы прокликивать диалог.

**Применение.** Подключено в `ShellSafetyAnalyzer.analyze/analyzeLine` и оба места разрешений —
`preToolUse` ACP-агента и создание терминала; проверка «путь» складывается с прежними причинами
(`rm-binary`, `protected-journal`) в один диалог. Тест-вектор: `npm run x -- --save /VolumES` при
проекте `/Users/a/proj` — `path-root`. Тест `CommandPathsTest`.

**Разбор строки (20.11.2026).** Обратная косая черта экранирует только то, что иначе было бы
разделителем, кавычкой или `$`; перед буквой она остаётся символом слова. Иначе `C:\Windows\notepad.exe`
и `\\server\share` теряли косые и правило не видело путь — окно закрывалось ровно там, где нужно
(тест `windows drives and UNC shares`). «Просто относительным», то есть заведомо внутри проекта,
считается только путь без корня, без `~`, без переменной и без `..`: `~` и `$HOME` раскрываются в
домашнюю папку и потому всегда вопрос. Для `format D: /q` причины пути не добавляются: диск называет
`format-drive`, а `/q` — переключатель, а не файл в корне тома; лишние причины учат прокликивать диалог.
