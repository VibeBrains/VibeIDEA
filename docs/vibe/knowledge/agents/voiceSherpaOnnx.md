# Голосовой ввод на sherpa-onnx: нативка в плагине и конец фразы

**Роль:** [решение+грабли] · **Найдено:** 15.10.2026, перенос голосового ввода VibeIDE

## Решение

Расшифровка — локально, без Python, whisper и Homebrew на машине человека: sherpa-onnx 1.13.4 и те же модели, что
у VibeIDE. Русский — стриминговая T-one пишет черновик во время речи, по паузе фразу перекодирует GigaAM v3 CTC int8.
Каталог моделей — общий артефакт набора VibeBrains `voice/sttModels.jsonc`, адреса и SHA256 — только оттуда.
Модели качаются по согласию с точным размером, процентами и отменой; whisper.cpp остаётся запасным путём.

## Нативная библиотека в плагине JetBrains

- В Maven Central sherpa-onnx нет. jar с Java API лежит в плагине как module-library (`vibe-agent/lib/`), а нативка
  для каждой платформы — в отдельных jar релизов k2-fsa/sherpa-onnx; качается `vibe-plugins/deps/download.sh`
  и кладётся только в образ своей платформы через `withPlatformBin`: `plugins/vibe-agent/native/<os-arch>/`.
- Родной загрузчик sherpa-onnx ищет библиотеку в `java.library.path`. Он выключается
  (`LibraryLoader.setAutoLoadEnabled(false)`), и библиотеки грузятся `System.load` по абсолютному пути из каталога
  плагина: сначала ONNX Runtime, потом JNI. У JNI-библиотеки `LC_RPATH @loader_path`, так что соседи находятся сами.
- Упаковку видит только гейт дистрибутива после сборки: раздел о sherpa-onnx в `checkVibeDist.sh` проверяет класс
  `OnlineRecognizer` в jar плагина и обе библиотеки с лицензиями в `native/`.

## Грабли

- **T-one в 1.13.4 не сообщает о конце фразы.** `isEndpoint` молчит и после пяти секунд тишины, метки времени при
  этом работают. Конец фразы определяется по тексту: стриминговая модель не меняет его 0,8 с после речи; плюс
  пять секунд тишины без речи и потолок 28 с на фразу. У VibeIDE ядро то же — им передано проверить у себя.
- **Модели в процессе IDE.** Обе модели вместе — около 1,1 ГБ памяти, и падение нативного кода уронит IDE.
  У VibeIDE движок в отдельном процессе. У нас модели выгружаются после простоя (настройка, по умолчанию 300 с);
  отдельный процесс — следующий шаг, если падения появятся.
- **Черновик в поле ввода размножается**, если вставлять его по запомненной позиции: человек может кликнуть
  или напечатать в середине. `VoiceSlot` перед каждой заменой сверяет якорь с текстом поля.

## Замеры

На arm64, JBR 25: первая загрузка нативки 1,6 с, повторная — 26 мс; T-one грузится 0,7–0,8 с, GigaAM — 0,5 с;
7,4 с речи расшифровываются потоком за 0,3 с, финальный проход — 0,2 с. Фраза `say -v Milena` распознана дословно.
