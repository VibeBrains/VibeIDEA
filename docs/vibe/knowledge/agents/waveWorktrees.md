# Шаги волны в своих рабочих деревьях

**[решение+грабли]**

## Контекст

Граница записи шага (`paths`/`denyPaths`) держит запись через IDE и запись, о которой агент спрашивает.
Адаптер Claude правит файлы своими инструментами и в режиме без вопросов до клиента не доходит вовсе.
Раздельность волны держалась на его честности, а спека обещала «единственную точку записи».

## Суть

Пишущий шаг волны работает в своём git worktree (решение №125), и изоляция больше не зависит от того, через кого пишет агент.

Грабли, на которых легко ошибиться:
- **Дерево от `HEAD` теряет работу.** Шаги пайплайна не коммитят, и дерево от `HEAD` не видит того, что сделали шаги до волны. Дерево начинается со снимка рабочего каталога — того же чекпоинта волны (`git worktree add -b <ветка> <путь> <снимок>`).
- **`git apply --3way` подразумевает `--index`.** Он требует, чтобы файлы совпадали с индексом, а правки предыдущих шагов и человека в индексе не лежат. Патч применяется через свой временный индекс, собранный из рабочего каталога (`GIT_INDEX_FILE`), — индекс человека не трогается.
- **Объекты общие.** Коммит в дереве виден из основного репозитория сразу, поэтому патч — обычный `git diff <снимок> <ветка>` из корня проекта.
- **Пересечение — не отказ, а маркеры.** `--3way` оставляет конфликт в файле и печатает «with conflicts»; дерево остаётся для слияния вручную, прогон останавливается.
- **Пути изменённых файлов — из дерева.** Шаг отчитывается путями внутри `.vibe-worktrees/…`, а следующие шаги читают файлы проекта: пути пересчитываются до отчёта шага (`StepWorktrees.rebase`).
- **Индекс IDE.** Дерево внутри проекта — вторая копия исходников; без исключения (`directoryIndexExcludePolicy`) каждый поиск и переиндексация удваиваются. Исключены и деревья Claude Code (`.claude/worktrees`).
- Имена как у VibeIDE: `.vibe-worktrees/vibe-agent-…`, каталог в `.git/info/exclude`.

## Как применять

- Сервис — `pipelines/StepWorktrees`, тест на живом git — `StepWorktreesTest` (две правки поверх незакоммиченной правки человека, конфликт, пустой шаг).
- Дерево начинается без установленных зависимостей: гейты, которым нужна сборка, имеет смысл ставить шагом после волны.
- Живым агентом не проверено.
