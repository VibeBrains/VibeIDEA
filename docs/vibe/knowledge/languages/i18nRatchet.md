# Храповик локализации: чем считать русские литералы

**Дата:** 2026-08-30 · **Ветка:** next · **Файлы:** `vibe-plugins/tools/checkVibeI18n.sh`, `i18nExclusions.txt`

## Грабли

Планка храповика считалась так:

```sh
grep -o '"[^"]*[А-Яа-яЁё][^"]*"'
```

POSIX-grep на macOS сравнивает диапазон `А-Я` **по байтам UTF-8**, а не по кодовым точкам. В этот
диапазон попадают типографские знаки, которых в нашем UI полно: `—`, `·`, `…`, `«»`, `▸▾`, `›`.
Из 75 «русских литералов», стоявших в планке к концу переноса, настоящей кириллицей была **одна**
строка — остальное были стрелки и разделители.

Последствие не в неточности числа, а в том, что гейт переставал ловить главное: планка держалась
на пунктуации, и новая непереведённая кнопка пряталась в этом шуме, не поднимая счётчик выше планки.

## Как правильно

Счёт ведёт python по кодовым точкам `[Ѐ-ӿ]`, по литералам (`"..."` с учётом экранирования),
с вырезанными комментариями:

- комментарии в коде по правилам проекта английские, а редкая кириллица в них — цитата или пример;
- считать их значило бы держать планку выше нуля из-за текста, который на экран не попадает.

После починки планка **0**: любая русская строка в коде мимо каталога валит гейт. Проверено подсадкой
строки в `ThoughtsBlock` — гейт провалился, после отката снова зелёный.

## Что кладётся в исключения

Только то, чего человек не увидит **никогда**, и с причиной в строке:

| Файл | Почему |
|---|---|
| `DesignPhrases`, `SecurityPhrases` | регэкспы детекторов — ищут русские слова в чужой странице; перевод сломает поиск |
| `PipelinesFile` | преамбулы ролей уходят в промпт, их язык — часть контракта пайплайна |
| `WatchPrompt` | текст промпта модели по разобранному видео |
| `DesignContextFile` | заголовки разбора markdown + блок дизайн-контекста для промпта |
| `HttpApiPolicy` | тело ответа HTTP API — контракт для чужих скриптов (`httpApiSpec.md`) |
| `CodeGraphStore`, `CodeGraphBuilder` | значения в `.vibe/codeGraph.json` — формат по `codeGraphSpec.md` |

Исключение выдаётся **файлу**, поэтому файл, где рядом лежат и паттерны, и сообщения находок,
сперва разрезается: так из `DesignStyleRules` был выделен `DesignPhrases`, иначе исключение спрятало
бы ~29 интерфейсных строк.

## Смежное

- Строка каталога в `const val` не компилируется и, что важнее, замораживает язык на моменте
  инициализации класса: правильная форма — `val X: String get() = t("ключ")`.
- Ключ, собранный конкатенацией (`t("cache.word.$unit")`), гейт не видит: он ищет литералы. Такие
  ключи пишутся полностью в `when`.
