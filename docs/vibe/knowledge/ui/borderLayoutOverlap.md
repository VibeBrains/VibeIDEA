# BorderLayout при нехватке ширины не сжимает и не переносит — он накладывает

**Дата:** 21.09.2026 · **Ветка:** next · **Статус:** правило + замер

## Симптом

Снимок владельца: строка состояния «Инструмент: Выполнить команду — npm install -g
@vtsls/language-server» лежит **поверх** шапки композера с «Нет файлов с изменениями» и иконками.
Две строки в одной полосе, читать нельзя ни ту, ни другую.

## Причина

```kotlin
override fun getMinimumSize(): Dimension = preferredSize   // StatusDot
```

Минимум равен предпочтительному, а предпочтительный растёт с длиной текста. Компонент лежал в
`BorderLayout.EAST` рядом с полоской действий в `WEST`.

`BorderLayout` отдаёт `EAST` и `WEST` их предпочтительную ширину и **не проверяет, поместились ли
они**: при нехватке места он не сжимает, не переносит и не усекает — он кладёт одно поверх другого.
Пока состояние было словом «Готово», ширины хватало; длинное имя инструмента её съело.

## Почему это знакомо

Это тот же класс дефекта, что **трижды** обрезал страницы настроек (`settingsPageWidth.md`):
несжимаемый минимум плюс раскладка, которая при нехватке места теряет содержимое молча. Там
минимум задавал `ComboBox`, здесь — наш собственный компонент; следствие одно.

## Правило

- **Минимум компонента с текстом не равен предпочтительному.** Минимум — сколько нужно, чтобы
  остаться понятным (точка и несколько символов), а не сколько нужно, чтобы показать всё.
- **Длинный текст усекается сам, с многоточием**, а полный остаётся в подсказке. Обрезанный молча
  текст неотличим от короткого — многоточие называет, что сказано не всё.
- **Строка, длина которой не ограничена содержанием, не делит полосу с соседями.** Имя инструмента
  приходит извне и может быть любым, поэтому состояние живёт собственной строкой.
- **Мерить итог, а не свойство.** `StatusStripLayoutTest` меряет сжимаемость и усечение — проверено
  возвратом старого минимума, замер падает. Замер положения строк там же честно назван описанием
  схемы: `ComposerPanel` требует `Project`, и фикстуру ради одного положения не поднимали.
