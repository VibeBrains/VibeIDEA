# Swing-лента чата: вертикальное растяжение BoxLayout
← [Knowledge Index](../README.md)

## [баг] Строки ленты без maxHeight растягиваются на весь вьюпорт

**Контекст:** 2026-08-23, редизайн панели Vibe Agent. Лента — вертикальный BoxLayout в JBScrollPane. Владелец увидел «кошмар»: при паре сообщений каждое растянуто на пол-экрана, подписи уплыли от текста.

**Суть:** BoxLayout распределяет ЛИШНЮЮ высоту между потомками пропорционально до их `maximumSize`; у JPanel он неограничен по умолчанию → строки чата раздуваются, пока контента меньше вьюпорта. Второй дефект той же сборки: пузырь в `BorderLayout.CENTER` занимает всю ширину, а не ширину контента.

**Применение:** каждая строка ленты — `ChatRow` с `getMaximumSize() = (maxW, preferredSize.height)`; вьюпорт скролла — обёртка `BorderLayout` с лентой в `NORTH` (двойная страховка: стек прижат кверху при любых maximumSize). Ширину пузыря резать распоркой/капом, не отдавать CENTER.

**Антипаттерны:** отдавать UI без визуальной проверки — компиляция и «классы в jar» не гейт для интерфейса; гейт UI — глаза (скриншот/запуск). Проверка экрана из сессии требует разрешения Screen Recording терминалу — без него `screencapture` возвращает «could not create image from display».
