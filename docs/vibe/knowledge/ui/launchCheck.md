# Проверка сборки запуском: отдельный профиль, а не глаза владельца

**Дата:** 20.09.2026 · **Ветка:** next · **Статус:** метод

## Зачем он понадобился

Темовая чехарда (`themeParentId.md`, `halfSwitchedLaf.md`, `themeSwitch.md`) жила месяц, и каждый
раз её приносил владелец снимком экрана. Юнит-тесты и гейты зеленели честно: они мерили форму
вызова и свойства компонентов, а сломанный результат виден только собранной IDE, поднятой целиком —
там, где платформа сеет `JBColor.DARK`, ставит таблицу умолчаний родителя и рисует диалоги.

## Метод

Профиль отдельный, чтобы не трогать рабочую IDE владельца — она в это время открыта, и её
`config` менять нельзя:

```
CHK=/Volumes/Storage/Caches/vibeidea-check
# idea.properties: idea.config.path / idea.system.path / idea.log.path внутрь CHK
# VibeIDEA.app копируется из СМОНТИРОВАННОГО dmg, затем xattr -dr com.apple.quarantine
IDEA_PROPERTIES=$CHK/idea.properties "$CHK/VibeIDEA.app/Contents/MacOS/idea"
```

Запуск через `Contents/MacOS/idea` даёт **свой** процесс рядом с установленной IDE: проверено
`ps -Ao pid,lstart,command` — два процесса с разным временем старта.

## Что смотреть

| Что | Где | Годный ответ |
|---|---|---|
| Таблица умолчаний темы цела | `grep -c 'no ComponentUI class' $CHK/log/idea.log` | ровно `0` |
| Схема редактора не залипла | `$CHK/config/options/colors.scheme.xml` | файла НЕТ (схема идёт за темой) либо назван нынешний |
| Тема применена целиком | снимок окна | интерфейс И центральная панель с кодом в одной гамме |

Снимок берётся только своего окна, а не всего экрана:

```
osascript -e 'tell application "System Events" to tell (first process whose unix id is <PID>) to get {position, size} of window 1'
screencapture -x -R"x,y,w,h" shot.png
```

## Грабли метода

- **Тему надёжнее менять перезапуском с правкой `laf.xml`, чем кликом.** Радиокнопки Swing
  не нажимаются ни `System Events`→`click at` (нужны права доступа у терминала), ни `AXPress`
  (`entire contents` большого окна падает `-10000`). Ввод текста тоже подводит: `keystroke`
  идёт через РАСКЛАДКУ, и на русской «Vibe Neon» превращается в «Vффф фффф».
- **Контраст проверки выбирать разительный.** Тёмная→тёмная разница спорна на глаз, а светлая
  `VibePorcelain` против тёмной отвечает однозначно: если код остался тёмным при светлом
  интерфейсе — схема не пошла за темой.
- **`themeId` в `laf.xml` — это id из `plugin.xml`** (`VibePorcelain`), а не имя темы
  («Vibe Porcelain»). Ровно та же ловушка, что стоила месяца в `themeParentId.md`.
