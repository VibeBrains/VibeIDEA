# Виджет задач в тулбаре виден не везде

**Симптом:** в одном проекте справа от виджета ветки стоит «PROMEDWEB-283561 ▾», в другом место пустое.

**Причина:** `plugins/tasks/tasks-core/src/com/intellij/tasks/actions/SwitchTaskAction.java:84` показывает комбо, только если
`isTaskManagerComboInToolbarEnabledAndVisible` (строка 110) истинно. Условие из трёх частей:

- активная задача не «исходная по умолчанию» (создана и обновлена не в один момент);
- есть не общий (`!isShared`) репозиторий трекера;
- включена настройка `TaskSettings.ALWAYS_DISPLAY_COMBO` (`tasks-api/.../TaskSettings.java:17`, дефолт `false`, приложение, `tasks.xml`).

В проекте без задач и без личного сервера трекера не выполнена ни одна часть, и действие скрыто.

**Решение:** `com.vibe.agent.tasks.TaskComboStartup` один раз на профиль настроек включает `ALWAYS_DISPLAY_COMBO`
(решение — чистая `TaskComboDefault`). Отметка `vibe.tasks.comboDefaultApplied` ставится всегда, поэтому выключенное
руками (Settings → Tools → Tasks) не возвращается. Активность подключена через необязательную зависимость от плагина
`com.intellij.tasks` (`vibe-tasks.xml`): без плагина задач она не грузится. Платформа не патчена.

**Пустое состояние:** у исходной задачи имя «Default task», его и показывает комбо; клик открывает переключатель.

**Не проверено:** вид в живой IDE (нужна сборка).
