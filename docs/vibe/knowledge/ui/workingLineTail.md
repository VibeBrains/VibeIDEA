# Индикатор хода — хвост ленты, а не строка хода

**Роль:** [баг+правило]
**Контекст:** владелец увидел строку «✻ Взвешиваю» НАД своим вопросом, вверху хода, а карточки инструментов — ниже (29.10.2026).

**Суть:** `WorkingLine` вставлялась в ленту один раз, при первом `showWorking`, и после этого не двигалась. Кто добавляет строку — тот и ставит её последней ровно в этот момент: `startTurn` зовёт `showWorking` до `userBubble`, поэтому вопрос человека ложился ПОД индикатор, а каждый следующий вызов инструмента — ещё ниже. Порядок «порядок задаётся при вставке» ломается на первом же добавлении после вставки.

**Применение:** место индикатора — свойство ленты, а не операция добавления, поэтому оно пересчитывается перед каждой перерисовкой (`revalidateScroll` → `keepWorkingLast`). Решение, надо ли трогать дерево компонентов, — чистая функция `WorkingLineOrder.targetIndex(rowsWithoutLine, currentIndex)`: она возвращает хвостовой индекс либо `null`, когда строка уже последняя. Тест `WorkingLineOrderTest` держит оба случая, включая «вопрос пришёл после индикатора». Перерисовка треда (`renderTranscript`) делает `removeAll()` и обязана привязать строку заново — иначе живой ход теряет индикатор до следующего `showWorking`.
