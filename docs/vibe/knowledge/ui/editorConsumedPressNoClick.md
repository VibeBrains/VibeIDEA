# Кнопки на инлеях редактора: после поглощённого нажатия клика нет

**Инцидент (сборка 0.9.5, 17.10.2026):** кнопки «Принять»/«Отклонить» над правкой (блок `HunkBlock`) ничего не делали, при этом полоса внизу работала.

**Причина:** `EditorImpl.MyMouseAdapter.mouseReleased` зовёт `mouseClicked` слушателей только если нажатие не поглощено (`myMousePressedEvent.isConsumed()`). Слушатель же поглощал нажатие, чтобы текст за кнопкой не начал выделяться, а действие вешал на `mouseClicked` — до него дело не доходило никогда.

**Решение:** нажатие поглощается и запоминается, действие срабатывает на `mouseReleased` над той же кнопкой (`PressedTarget`). `mouseReleased` слушателям приходит и после поглощённого нажатия.

**Урок:** кнопка, нарисованная на инлее, не может опираться на `mouseClicked`, если гасит нажатие; проверять по исходнику `EditorImpl`, а не по названию события.
