# Дозакачка истории shallow-клона против GitHub
← [Knowledge Index](../README.md)

## [квирк] `git fetch --deepen=N` бьётся об «error processing shallow info: 4»

**Контекст:** ночь основания 2026-08-23. Полный клон IC дважды рвался по сети (~6 GB монолитного пака нерезюмируемы), стратегия была shallow `--depth 1` + фоновая дозакачка кусками `--deepen=50000`.

**Суть:** против GitHub каждый `--deepen` завершался `fatal: error processing shallow info: 4` (21 попытка подряд, ни одна не прошла). Это известный класс отказов серверной обработки deepen-запросов на огромных репозиториях; ретраи не помогают.

**Применение:** для дозакачки истории использовать `git fetch --shallow-since=<дата>` с постепенным сдвигом даты назад (каждый шаг — отдельный некрупный пак, ретраится), либо `--unshallow` одним заходом при стабильной сети. После неудачных fetch-ей проверять `.git/objects/pack/` на мусорные `tmp_pack_*`.
